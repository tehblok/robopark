# Чистая установка с USB

Поддерживаются Ubuntu 22.04+ и актуальный Armbian на ARM64/AMD64, Python 3.10+.
Скопируйте единственный `.ota` с USB на локальный диск и выполните:

```sh
python3 robopark-<версия>.ota verify --json
sudo python3 robopark-<версия>.ota
```

Меню появляется до проверки Docker и сети. Для первого перехода со старой
ветки выберите «Чистая установка». Резервная копия старых данных не создаётся:
данные, вложения и кэши Robopark будут удалены безвозвратно. Проверьте список
целей и введите точную фразу `УДАЛИТЬ ВСЕ ДАННЫЕ`.

Пароль первого royal вводится скрыто дважды. Не передавайте его в командной
строке. Для диагностики без установки выберите пункт 3 или выполните:

```sh
python3 robopark-<версия>.ota diagnose --output /absolute/output/directory
```
