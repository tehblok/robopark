# Преднастроенная установка владельца

Профиль `robopark` предназначен для нового хоста владельца этого репозитория.
Он запускается из проверенного OTA-файла:

```sh
sudo python3 robopark.ota install --preset robopark
```

Он задаёт домен `robopark.ru.tuna.am`, логин владельца `tehblokdan` и резервный
SSH через Tuna `ssh` с прежним публичным ключом. Аппаратный профиль выбирается
по проверкам хоста. Хранилище проходит обычную проверку установщика: для
вариантов eMMC + NVMe и ОС на NVMe сохраняются штатные проверки диска и
подтверждение его подготовки. Форматирование по умолчанию не выполняется.

Установщик запросит ключ зашифрованных настроек, Tuna token и новый пароль
владельца с повтором. Вставка ключа скрыта, как при вводе пароля. Эти значения
не нужно передавать в аргументах команды. Неверный ключ отклоняется до установки
пакетов. Чистая установка откажет при найденных данных Robopark.

## Что восстанавливается

Источником служит сохранённая на ноутбуке конфигурация `tracker-report-server`:
11 парков, точные Tracker-теги, основные чаты и темы, почасовые отчёты,
расписания созвонов и текстовых рассылок, чередование A/B и исходный часовой
пояс `Europe/Moscow`. Токены Tracker и Telegram также перенесены из этого
источника. Их действительность проверяется уже на доступном хосте; локальная
проверка импорта не обращается во внешние сервисы.

Все задания импортируются выключенными, рассылки поставлены на паузу.
После первого входа royal проверяет получателей и время во вкладке Telegram,
включает нужные задания и снимает паузу. Привязки сотрудников и администраторов
создаются через учётные записи Robopark; старые Telegram whitelist не дают
автоматического доступа.

Это частичное восстановление конфигурации, а не резервная копия хоста.
Прежние пользователи, пароли, сессии, cookies Emergency/Inventory, журналы,
прочие настройки сервисов и история Robopark в этот набор не входят.
Tuna token нужно ввести заново. ИИ на Khadas остаётся выключенным.

## Хранение и защита

В публичном Git и OTA находится только
`deploy/support/robopark-install-preset.enc` — Fernet-архив с аутентификацией.
Ключ хранится отдельно, в переданном владельцу `robopark-install-preset.key`.
Это отдельный ключ, он не заменяет прежний AGE identity для копии SSH-ключа.
Сохраните его вне публичного Git. Сам закрытый SSH-ключ в preset не входит.

Ключ установки создаётся как временный файл `0600`, монтируется только в
одноразовый seed-контейнер и удаляется при завершении процесса установки.
В случае аварийного выключения до завершения файл может оставаться в `/run`
до перезагрузки. Токены в новой базе повторно шифруются ключом нового хоста.
Импорт выполняется одной транзакцией; конфликт не оставляет частично созданные
парки и задания. Повтор того же импорта идемпотентен, существующая конфигурация
не перезаписывается.
