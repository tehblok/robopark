# Обновление через сайт

Только royal открывает «Система → Обновление», выбирает один `.ota` и ждёт
локального расчёта SHA-256. Браузер показывает версию и изменения из manifest,
загружает файл частями и продолжает прерванную загрузку после повторного выбора
того же файла. Страница не перезагружается во время загрузки.

После завершения загрузки royal повторно подтверждает личность и запуск.
Сервер ещё раз проверяет контейнер и SHA-256, делает snapshot, применяет
миграции и readiness. При ошибке выполняется автоматический rollback. Интерфейс
один раз обновляет оболочку только после изменения build id.

Стабильные причины отказа: `ota_hash_mismatch`, `ota_invalid_container`,
`ota_incompatible`, `ota_insufficient_space`, `ota_upload_not_found`,
`host_work_in_progress`, `rollback_failed`. Не обходите проверку повторной
упаковкой; скачайте диагностику на той же странице.
