# Robopark RC44 — Khadas, AGX Orin и Mac Emergency

Тестовый выпуск `0.2.0-rc.44.dev7114536505405942333`. Один серверный OTA
для поддерживаемых Ubuntu/Armbian ARM64 на Khadas VIM4 и AGX Orin; отдельный
установочный pkg для macOS 13+ на Apple Silicon. Роль test/production задаётся
при установке и не зависит от модели сервера.

Добавлены регистрация и отзыв Mac, отдельный процесс Emergency broker,
исходящий WSS, выбор исполнителя по готовности/задержке/нагрузке, привязка
к серверному UUID и окружению. Права получателя и источника проверяются сервером.
Новый Mac ожидает явного одобрения admin/royal; привязка к серверу подтверждается
подписанным deployment profile. Mac хранит корпоративную сессию в Keychain. Внешние TCP-порты Mac и новые
Mac-туннели Tuna не нужны.

Установщик размещает приложение и пользовательский LaunchAgent. Локальная
панель показывает подключения и обновления; вход в Emergency выполняется
в WebKit. Обновления проверяются по подписанному каталогу с выбором
«Обновить / Позже». API раздаёт каталог и pkg независимо от визуального сайта.

Инструкция: [тестовая установка](../runbooks/test-release.md).
Проверки и границы: [отчёт выпуска](../verification/2026-10-13-macos-test-release.md).

## Ограничения пилота

- Физическая установка на Khadas/AGX и корпоративный SSO этого Mac требуют
  проверки на целевых устройствах; SSH будет предоставлен позже.
- На машине сборки отсутствуют Developer ID Application/Installer identities.
  Пилотный pkg не имеет Apple notarization; подпись каталога не заменяет её.
- WSS защищает соединение до TLS origin. Сквозная недоступность payload для
  Tuna при TLS-терминации у посредника не реализована.
- Дополнительные вычисления/OCR/AI и обход серверного Wi-Fi для крупных файлов
  остаются следующими этапами. GPU/DLA не обещаются на Khadas, модели не включены.
- Полная автономная копия рабочих данных в Mac-клиент не добавлена. Локальная
  панель работает офлайн, рабочие черновики обслуживаются существующим web/PWA.
- Серверный OTA остаётся в существующем hash-only формате. Снимок БД обязателен
  перед обновлением схемы до `0063_agent_devices`; не считать downgrade миграции
  заменой восстановления согласованного снимка.
