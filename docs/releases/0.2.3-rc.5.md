# Robopark 0.2.3-rc.5 — открытие встроенного интерфейса Mac

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не переключаются.

Исправлена ошибка `{"detail":"bundled_workspace_unavailable"}` при открытии
приложения. Файлы интерфейса присутствовали в установленном RC4; локальный
обработчик отклонял начальный путь `/`, потому что URL каталога из `Bundle.main`
содержал базовый URL и не был равен нормализованному абсолютному URL того же
каталога. Теперь сравниваются нормализованные файловые пути. Проверка выхода
за пределы каталога, включая символические ссылки, сохранена.

Добавлена проверка production-обработчика в настоящей временной структуре
`.app`, включая начальный адрес, маршруты интерфейса и защитные ограничения.
Проверка может использовать ресурсы готового приложения, не меняя его данные
и не обращаясь к пользовательскому Keychain.

Установите `Robopark-0.2.3-rc.5-arm64.command` поверх RC4. Аккаунт, закрепление
Mac и локальные данные сохраняются. Установщик требует штатные права
администратора macOS. Тестовый пакет по-прежнему без Apple Developer ID и
notarization; защиты macOS не отключаются.

Для уже переведённого в TEST Khadas используйте обычное обновление серверным
OTA, чтобы обновить раздаваемый каталог Mac. Повторять первоначальный перевод
из production RC43 и удалять его состояние не нужно. Если первоначальный RC4
переход ещё не завершён, продолжайте соответствующим RC4 setup2.

Новых миграций и изменений корпоративных прав нет. Серверная архитектура,
офлайн-режим и распределение из RC3 сохранены; исправления установки RC4 и
Khadas setup2 также включены. Фактическая проверка личного входа и
корпоративных доступов требует аккаунта владельца.
