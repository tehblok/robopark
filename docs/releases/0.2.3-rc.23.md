У Mac отдельная долгоживущая сессия WSS: обычный HTTP-дедлайн больше не
обрывает активный WebSocket через 120 секунд. Брокер отключает транспортное
per-message deflate; ограниченное сжатие полезной нагрузки сохраняется.

Для пакетных чтений увеличен лимит одного пользователя с 16 до 64 при общем
лимите 256. Ограничения очереди, параллельной работы Mac и частоты обращений к
корпоративному источнику сохраняются. Диагностика отказа записывает категорию
и число попыток без содержимого запросов и токенов.

Временная ошибка чтения отдельного робота больше не сбрасывает ранее
подтверждённую готовность всего Mac. Истечение срока проверки, отказ
авторизации и неуспешная проверка доступности по-прежнему учитываются.

Удалена панель «Роботы в работе» с фильтрами и её фоновая офлайн-загрузка.
Поиск по номеру/VIN и проверка выбранного робота остаются.

Внешний Inventory проверяет доступность сервера короткой одиночной пробой,
не создавая одновременную волну одинаковых сетевых ожиданий. Inventory остаётся
необязательной интеграцией для будущих функций: его статус показывается отдельно
и не блокирует общую готовность Tracker/Emergency.

Проверки исходников и итог живого нагрузочного прогона фиксируются в verification.json
релиза. Это тестовый кандидат: 700 роботов на карте и 200+ физических клиентов
требуют отдельной приёмки, её прохождение этот релиз не заявляет.
