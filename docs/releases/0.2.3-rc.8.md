# Robopark 0.2.3-rc.8 — Tracker pagination and Mac connection recovery

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не переключаются.

Исправлена загрузка следующих страниц Tracker. Ссылка, которую возвращает
корпоративный API, содержит `staleOk` и пустые поля проекции; раньше шлюз
отклонял её, и реестр роботов отвечал 502, блокируя подготовку офлайн-данных.
Теперь логический флаг проверяется и сохраняется, пустые проекции нормализуются.
При резервном чтении через Mac сохраняется исходный метод и тело запроса,
необходимые SDK для пагинации. Адреса, права и владелец запросов остаются
ограничены прежним контрактом.

Фоновые каналы Mac получили ограничение времени рукопожатия и подтверждение
heartbeat. Зависшее соединение закрывается и переподключается; старый таймер
не может закрыть новый канал. Для предыдущего сервера используется WebSocket
ping. Исправлена передача действия при проверке полномочий корпоративной записи.

Страница «Этот Mac» обновляет статус фоновой службы и установленного обновления
без перезагрузки. Опрос обращается только к localhost и приостанавливается,
когда вкладка скрыта.

Khadas обновляется штатным `robopark-0.2.3-rc.8.ota` или комплектом
`Robopark-Khadas-Test-0.2.3-rc.8-update.zip`. Новых миграций базы нет.
Mac получает обновление через подписанный тестовый каталог; локальный установщик
— `Robopark-0.2.3-rc.8-arm64.command`. Для запуска нового двоичного файла
может потребоваться штатное разрешение доступа к Keychain.

Проверки включают пагинацию настоящего SDK, строгую валидацию параметров,
проверки владельца, пропущенные и устаревшие heartbeat ACK, совместимость
каналов и native-проверки Mac. Результаты live-проверки публикуются отдельно:
успешная сборка не заменяет проверку корпоративного входа и офлайн-синхронизации.
