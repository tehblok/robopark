Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не переключаются.

Исправлен сбой обзора Tracker: служебный токен мог читать задачи и счётчики,
но получать 403 при дополнительной загрузке профиля автора или исполнителя.
Теперь 403/404 такого профиля сохраняет доступную задачу и встроенное имя.
Недоступный профиль запрашивается не более одного раза за поиск. Числовой
идентификатор пользователя не подставляется вместо корпоративного логина.

Отказы доступа к самим задачам и поиску по-прежнему возвращаются как ошибки.
Токен, права, владелец запроса и правило «сервер первым, Mac как резерв при
недоступности» не меняются.

Обновление уже тестового Khadas: штатный OTA `robopark-0.2.3-rc.7.ota` либо
комплект `Robopark-Khadas-Test-0.2.3-rc.7-update.zip`. Повторный перевод хоста
из production не нужен. Новых миграций базы нет.

Mac получает соответствующую версию через подписанный тестовый каталог.
Для локальной установки доступен `Robopark-0.2.3-rc.7-arm64.command`.
Функции Mac соответствуют RC6: локальный браузерный интерфейс, фоновая
служба, сохранённая сессия, офлайн-очередь и личный корпоративный вход.
Apple Developer ID/notarization отсутствуют; macOS может запросить доступ
новой сборки к сохранённой сессии Keychain. Защита macOS не отключается.

Регрессии проверяют настоящие SDK-ссылки пользователей: 403, 404, кеширование
отрицательного результата, успешное получение логина и обязательный отказ
при 403 поиска задач. Live-проверки записываются отдельно после OTA;
сборка сама по себе не доказывает синхронизацию или корпоративный SSO.
