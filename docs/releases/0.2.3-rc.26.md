Убрана синхронная проверка автозапуска из каждого обновления интерфейса Mac и ответа локального статуса. Раньше получение и завершение каждого задания запускали launchctl на основном потоке, задерживая сетевые ответы и heartbeat.

Состояние автозапуска теперь читается из кэша. Проверка при запуске и после изменения настройки выполняется отдельно с таймаутом 3 секунды и объединением параллельных запросов. Настройка автозапуска сохраняет прежний смысл.

Корпоративные доступы, правила владельца и параллельность не изменены. Проверки роботов при приёмке выполняются только чтением. Результат 60 роботов за 5 минут публикуется отдельно в verification.json; до его завершения стабильность под этой нагрузкой не заявляется. 700 роботов и 200+ пользователей требуют отдельной приёмки.
