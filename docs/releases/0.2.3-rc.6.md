# Robopark 0.2.3-rc.6 — сервер первым, Mac как резерв

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не переключаются.

Обычные корпоративные чтения выполняются через настроенный серверный доступ.
Пул Mac используется только для недоступного серверу ресурса или после
транспортного сбоя/5xx. Следующий запрос снова пробует сервер. Отказ в доступе
не меняет исполнителя. Начатые записи сохраняют автора и квитанцию: после
неизвестного исхода повтор на другом устройстве не выполняется.

Сервер использует свой служебный Tracker-токен. Mac получает личный OAuth
владельца в общем корпоративном входе вместе с настройкой Emergency/Inventory.
Корпоративный логин по умолчанию совпадает с логином Robopark; существующее
явное сопоставление сохраняется. Личный токен остаётся в Keychain владельца.
Исправлен запрос пользователя Tracker, который SDK делает при загрузке
исполнителя задачи: раньше он приводил к `unsupported_gateway_operation`
и ошибке обзора даже при исправном серверном токене.

Приложение открывает локальный интерфейс в системном браузере; служба
продолжает работать в фоне. Раздел «Этот Mac» показывает связь, синхронизацию,
корпоративные доступы, обновления и автозапуск. Статус корпоративного входа
обновляется автоматически. Системные экраны, граф сети и технические API
доступны только Royal, включая прямые запросы к серверу.

Локальный посредник сохраняет обязательные заголовки изменений Tracker,
резервной обработки, привилегированных операций и продолжения загрузки OTA.
Изображения и вложения открываются через авторизованный локальный запрос.

Локальная браузерная авторизация использует отдельный ключ текущего запуска
службы и одноразовую передачу при открытии приложения. Ключ не передаётся
другим localhost-портам; серверная сессия остаётся в Keychain. Выход завершает
локальную сессию. После перезапуска службы снова откройте Robopark через
приложение, чтобы восстановить доступ браузера без повторного ввода пароля.

Устаревшая вкладка после входа в другой вкладке также требует открытия через
приложение. Она больше не сбрасывает действующую сессию и общий офлайн-кэш.

Черновики старого встроенного окна не переносятся автоматически в браузер.
При наличии старой базы доступен пункт «Черновики предыдущей версии» для
открытия и синхронизации в прежнем хранилище. Удаление с очисткой удаляет
Keychain и данные прежнего окна; данные сайта `127.0.0.1` в системном браузере
удаляются отдельно в настройках браузера.

Mac: запустите `Robopark-0.2.3-rc.6-arm64.command` поверх установленной версии.
Для уже тестового Khadas используйте `Robopark-Khadas-Test-0.2.3-rc.6-update.zip`
и штатный OTA. Повторять перевод production RC43 в test не требуется.
Новых миграций нет. Пакет Mac без Apple Developer ID/notarization; установщик
не отключает защиту macOS.

Пределы: работа без сервера опирается на сохранённые данные и поддерживаемую
очередь; новый удалённый job требует координатора. Relay расходует канал
сервера. Мессенджер, VPN и DHT не входят в выпуск. Проверки на одном ноутбуке
не заменяют полевую приёмку нескольких Mac и личного корпоративного SSO.
