# Robopark 0.2.3-rc.1 — Mac-пул и установщик тестового Khadas

Тестовый prerelease на базе **Robopark 0.2.2 — AGX network and Tuna recovery**.
Стабильный релиз 0.2.2 и production не переключаются. Тестовый сервер использует
`https://roboparktest.ru.tuna.am`; дополнительные TCP/SSH-порты Tuna не нужны.

- Mac: закреплённый test origin, вход в аккаунт, рабочая система, состояние
  сервера/синхронизации, управление автозапуском и подписанные автообновления.
- Авторизованный Mac автоматически включается в доверенный пул и закрепляется
  за первым сотрудником. Повторный вход другого сотрудника не перехватывает устройство.
- В интерфейсе системы — граф сотрудников и Mac, включая отключённые устройства,
  измеренные задержки и скорость ответов, нагрузку и состояние доступа к Emergency.
- Распределение чтения Emergency учитывает качество соединения, загрузку,
  перегрев, число заданий и свежесть телеметрии. Записи остаются централизованными.
- Офлайн сохраняются ранее загруженные данные и очередь поддерживаемых действий.
  Фото обрабатываются локально, увеличившийся результат не отправляется;
  зависший обработчик прекращается с сохранением оригинала.
- Однофайловый установщик переводит старый Khadas RC43 в test с проверенным
  backup, изоляцией старых интеграций и отдельной идентичностью стенда.
- Сохранены исправления загрузки AGX, восстановления Wi-Fi, Tuna и BuildKit DNS из 0.2.2.

Проверены переход занятого Mac в нулевую ёмкость, конкурентная регистрация
устройств в PostgreSQL и распределение при 0/1/2/12/100 участниках. Готовность
Emergency подтверждается реальным чтением разрешённого VIN, а не наличием cookie.
После выхода из аккаунта bridge останавливается; после штатного перезапуска
сохранённый вход проверяется через сервер перед возобновлением работы.

Установка Khadas: [инструкция](../runbooks/khadas-test-transition.md).
При первом включении бывший production Khadas должен быть без доступа в интернет
до включения карантина установщиком. Mac-пакет предназначен для Apple Silicon.
Для автоматического выбора проверочного VIN на test надо настроить отдельную
Tracker-интеграцию и доступ сотрудника к парку. До этого Mac показывает ожидание
доступа и не объявляется готовым источником Emergency.

Миграция 0064 закрепляет ключ установки за первым владельцем. Если в старой базе
уже есть дубли одного ключа, она останавливается с `agent_device_identity_conflict`;
такие записи нужно разобрать отдельно, история автоматически не удаляется.

Этот пилот собирается без Apple Developer ID и notarization. Подпись каталога
Ed25519 и проверка хеша пакета работают, но macOS может потребовать разрешить
конкретный пакет или повторный доступ к Keychain после обновления. Массовая
раздача и бесшовные ежедневные обновления требуют Developer ID и проверки на Mac.

Серверный updater на test остаётся ручным; автообновление Mac относится только
к подписанным пакетам его test/rc-канала. Производительность на реальном парке
и установка на физический Khadas требуют аппаратной проверки.
