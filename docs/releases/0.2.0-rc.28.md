# Robopark 0.2.0-rc.28

Надёжность управления помощником, очистка истории и полнота инструкций.

- Отключение ИИ и удаление скрипта во время подготовки задания учитываются
  перед запуском. Временная занятость оставляет ещё не начатое задание в очереди.
- Готовый ответ сохраняется с повторной проверкой прав и ревизий после ожидания
  системной операции. Модель и скрипт не запускаются повторно. Длительная занятость
  завершается понятной ошибкой вместо зависшего статуса «выполняется».
- Удаление источника согласовано с проверкой и записью результата. Медленный
  Tracker не удерживает административную блокировку. После временной ошибки
  финальной записи в БД следующий проход восстанавливает статус задания.
- Обработка закрытых ремонтов согласована с отключением обучения и удалением
  знаний. Настройки перечитываются после ожидания административной блокировки.
- Очистка истории удаляет старые завершённые тесты скриптов и черновики без
  беседы. Активные задания, знания, правила и квитанции внешних действий
  сохраняются. Интерфейс показывает отдельные количества удалённых записей.
- Выдержка длинной инструкции сохраняет начальные условия вместе с найденным
  шагом, если они помещаются в прежний лимит. На 18 вопросах разработки нужный
  фрагмент находится в 18 случаях вместо 17; это проверка поиска, не модели.
  Проверочные вопросы включены в Git и исполняются без приватных материалов.
- Удалён неиспользуемый конструктор промпта без ограничения контекста.

Схема БД остаётся `0058_ai_bundle_receipts`; OTA v1 и восстановление снимком
сохранены. Публичная база из 4 706 записей не изменяется. ИИ устанавливается и
работает только на подтверждённом AGX Orin. Физическая приёмка GEACX1 и Bonsai
остаётся отдельной работой; восьмичасовой тест не выполняется.

Проверки и границы результатов — в
[отчёте](../reviews/2026-10-04-ai-controls.md).
