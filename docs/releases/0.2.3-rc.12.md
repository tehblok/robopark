# Robopark 0.2.3-rc.12 — Mac sessions without Keychain prompts

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не обновляются. OTA совместим с RC9, RC10 и RC11.

Сессии и ключи Mac сохраняются в собственном каталоге Robopark текущего
пользователя macOS (0700/0600). Обычная работа и обновления больше не зависят
от разрешений Keychain и изменения подписи приложения. Пароль не сохраняется.
Это файловое хранение с ограничением прав, без отдельного шифрования самих файлов;
офлайн-снимки, очередь и медиа по-прежнему шифруются AES-256-GCM.

Старые Keychain-записи только читаются при переносе и сохраняются. Если старый
вход недоступен, приложение открывается и позволяет войти заново. Старый
офлайн-ключ и квитанции незавершённых операций не заменяются пустыми данными:
до переноса ключа старые офлайн-данные остаются недоступны. Истечение/отзыв
корпоративной сессии и MFA регулируются корпоративным провайдером.

Исправлен `bundled_workspace_unavailable` при запуске из временного каталога:
локальный интерфейс корректно обрабатывает `/private/tmp` и `/tmp`.
Успешная загрузка парков с сервера больше не превращается в сетевую ошибку,
если недоступна локальная запись офлайн-кэша.
Удаление с `--remove-data` включает новое хранилище; обычное удаление сохраняет его.

Комплект содержит Mac `.command`/`.pkg`, OTA и архив обновления тестового Khadas,
документацию и раздельные отчёты сборочных и живых проверок. Подписанный каталог
предназначен для существующей службы автоматического обновления Mac.
Apple Developer ID и notarization пока отсутствуют. Новая системная установка
может требовать прав администратора; уже установленный updater работает без
повторного пароля. Серверный OTA сохраняет штатное подтверждение Royal.
