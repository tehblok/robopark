# Robopark 0.2.0-rc.27

Защита хранилища AGX и ограниченное выполнение скриптов.

- Managed storage проверяет, что Docker и containerd продолжают использовать
  предусмотренные каталоги. Перенаправление рабочих данных на eMMC или чужой
  диск блокирует операцию вместо незаметной записи вне NVMe.
- OTA обновляет systemd-защиту для новых служб. Повторная подготовка готового
  layout восстанавливает актуальные drop-in; отсутствие нужного NVMe остаётся
  причиной остановки операций.
- Sandbox обслуживает ввод и вывод под общим deadline, ограничивает объём
  сохраняемого вывода и закрывает процесс/pipe при ошибках и таймауте.
- Удалены 117 исторических исключений для неотслеживаемых исходников и
  автоматическое включение новых файлов legacy-бота в архив рабочего дерева.
  Новые runtime-файлы должны быть проверены и добавлены в Git перед упаковкой.
- Исправлено сохранение артефактов браузерных тестов помощника внутри
  непривилегированного Linux-контейнера.

БД остаётся `0058_ai_bundle_receipts`; OTA v1 и восстановление снимком сохранены.
Публичная база из rc.26 включена. Legacy-хосты без managed layout продолжают
прежний режим. ИИ запускается только на подтверждённом AGX; на физическом
GEACX1 ещё нужна приёмка. Восьмичасового прогона нет.
