# Robopark 0.2.0-rc.31

Итоговый кандидат текущего прохода стабильности. Включает изменения rc.29 и
rc.30: ограничение кэшей и хранения медиа, сохранность offline-данных и фото,
исправления блокировок, навигации и удаление неиспользуемых экранов задач.

Дополнительно:

- Ошибка CacheStorage больше не подменяет успешный сетевой ответ ошибкой.
  При недоступном кэше навигация обращается к сети; терминальные ресурсы
  исключены и из runtime-кэша.
- Создание разговора имеет один активный запрос. Ошибка позволяет повторить
  попытку с сохранённым черновиком. Поздний ответ не меняет выбранный тикет.
- Удаления используют актуальный список и выбор. Они не возвращают удалённые
  записи, не закрывают другой разговор и останавливают его старые запросы.
- При возврате в незавершённый разговор опрос задания возобновляется.
  Финальный ответ не заменяет беседу, выбранную позднее.

База знаний содержит те же 4 706 записей. Сохранены БД 0058, OTA v1,
обновление с перечисленных в manifest версий и ограничение ИИ AGX Orin.

Адресная проверка: 61 тест помощника, 27 API-тестов управления заданиями,
18 браузерных сценариев Chromium/Firefox/WebKit, frontend lint/build и
API Ruff check/format. Отдельно исправление CacheStorage прошло 53 script-теста
и 48 PWA-сценариев исходного среза. Финальная общая проверка и привязка
установочного архива выполняются перед публикацией.

[Создание разговоров](../reviews/2026-10-05-assistant-creation-ownership.md),
[удаление и ответы](../reviews/2026-10-05-assistant-deletion-ownership.md),
[отказ кэша](../reviews/2026-10-04-pwa-cache-failure.md).

Рабочий хост не обновлялся. Восьмичасовой тест не выполнялся по решению
владельца. Физические AGX/GEACX1, CUDA/Bonsai, камера, печать и iPhone/PWA
требуют отдельной аппаратной приёмки; этот кандидат её не заявляет.
