# Robopark 0.2.3-rc.2 — обработка на Mac и полноценное рабочее место

Тестовый prerelease для `https://roboparktest.ru.tuna.am` на базе 0.2.2 и
0.2.3-rc.1. Production и Latest stable 0.2.2 не переключаются.

Mac — основное приложение для операторов, администраторов и рояла. Полный
интерфейс входит в приложение; веб и PWA остаются поддерживаемыми клиентами.
Панель службы содержит вход, связь, синхронизацию, автозапуск и уведомления.
Офлайн доступны сохранённые данные и очередь поддерживаемых действий; свежие
данные и административные операции требуют связи с сервером.

- Свободные авторизованные Mac выполняют ограниченные задания обработки фото
  и CSV. Выбор учитывает занятость, CPU, память, нагрев и свежесть состояния;
  потеря устройства приводит к ограниченному повтору на другом Mac.
- Фото сначала обрабатывается на исходном устройстве. При необходимости оно
  передаётся свободному Mac напрямую через зашифрованный WebRTC DataChannel.
  Сервер согласует соединение и подтверждает права, не пересылая исходное фото.
  Дополнительные публичные порты и Tuna-туннели не нужны.
- При несовместимых NAT, отсутствии свободных Mac или ошибке результата
  сохраняется локальная обработка/оригинал. Последняя загрузка результата в
  систему остаётся серверной: весь трафик Wi-Fi не устранён.
- CSV через Mac включается отдельно (`COMPUTE_CSV_OFFLOAD_ENABLED=true`).
  По умолчанию выключен: пересылка строк и результата увеличивает трафик сервера.
  Перед выдачей результат сверяется с разрешёнными строками выгрузки.
- Граф устройств показывает владельцев, доступность и загрузку. Отдельно видны
  compute и Emergency, объёмы прямых передач, завершения и fallback.
- Задачи, комментарии, возвраты, репорты, проверки, объявления и призывы доступны
  в уведомлениях. Техработы адресуются сотрудникам, инциденты системы/сети и
  восстановление — роялу. Системные баннеры macOS требуют разрешения пользователя.
- Основной установщик Mac — один `.command` со встроенным пакетом и SHA-256.
  Он поддерживает локальную установку/обновление; подписанный test/rc-каталог
  используется для автоматических онлайн-обновлений. Удаление доступно в меню
  приложения; локальные данные сохраняются, если отдельно не выбрано их удаление.

Mac: Apple Silicon, macOS 13+. Скрипт не отменяет проверки macOS: этот тестовый
выпуск не имеет Apple Developer ID/notarization. Если скачанный `.command` не
запускается двойным щелчком, выполните `bash ` в Terminal и перетащите файл после
пробела. Не отключайте Gatekeeper глобально.

Khadas: однофайловый `Robopark-Khadas-Test-0.2.3-rc.2.pyz` включает OTA и
проверенный test-профиль. Первый запуск бывшего production Khadas — без интернета
до включения карантина. [Процедура установки](../runbooks/khadas-test-transition.md).
Серверное OTA остаётся ручным; автоматические обновления относятся к Mac.

Два последовательных задания через настоящий WKWebView DataChannel и Swift
ImageIO прошли с настройкой STUN из приложения. Проверка проведена на одном Mac;
связь между физическими устройствами в разных сетях остаётся полевой проверкой.

Локальные проверки и точный исходный commit перечислены в `verification.json`
комплекта. Установка на физический Khadas, корпоративный SSO и производительность
реального парка требуют проверки на устройствах; эмуляция 100 клиентов её не заменяет.
