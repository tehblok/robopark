# Robopark 0.2.3-rc.21 — TEST SSH management and reconnect recovery

Тестовый prerelease для `roboparktest.ru.tuna.am`, совместим с RC20.
База остаётся на `0066_device_auth`. Production и Latest stable 0.2.2 не обновляются.

Для Royal добавлены отдельные подтверждаемые операции подготовки SSH,
включения SSH-туннеля и отключения SSH-доступа. Они выполняются через обычный
HTTPS-контур управления хостом, поэтому не зависят от подключения веб-терминала.
Используется существующая настройка support SSH и Tuna. Произвольные команды,
новые учётные записи и права sudo через эти операции не выдаются.

Подготовка поднимает только локальный SSH. Перед включением туннеля необходимо
освободить тот же алиас на предыдущем сервере. Само OTA SSH не включает.
На TEST снимается только соответствующая блокировка support-служб,
оставленная установщиком перехода с production. Общий разрешающий marker
production automation не создаётся. HTTP-туннель, приложение и бот этим
управлением не затрагиваются.

У Mac после успешно установленного соединения сбрасывается задержка повторных
подключений Emergency и Compute. Раньше накопленная задержка могла добавлять
до минуты после следующего обрыва. Успешная проверка корпоративного ресурса
сразу передаёт серверу обновлённую доступность устройства. Журнал отмечает
этапы heartbeat/probe/job без токенов и содержимого запросов.

Веб-терминал ограничивает ожидание начального подключения и protocol-ready
восемью секундами. Повтор использует новый билет той же подтверждённой сессии
внутри прежнего общего окна восстановления. Пароль, TOTP, срок действия
сессии и отзыв доступа сохраняются; введённые команды не повторяются.

RC20 на TEST и Mac установлена, личный вход сохранился. Успешные чтения
Emergency через Mac подтверждены, но чередуются с обрывами транспорта.
Перечисленные изменения улучшают диагностику и восстановление; стабильная
работа при 200+ пользователях пока не подтверждена. Корпоративный ProxyHelper,
системные proxy/DNS и проверка сертификатов не меняются.
