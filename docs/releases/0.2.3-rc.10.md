# Robopark 0.2.3-rc.10 — Corporate SSO recovery and Mac storage continuity

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не обновляются. Проверки сборки и живой установки описаны отдельно
в `verification.json` и `live-verification.json` комплекта.

Корпоративный Passport перенаправлял вход на `guard.oauth.yandex-team.ru`, которого
не было в списке RC9: приложение останавливало переход после ввода пароля.
Теперь окно поддерживает HTTPS-переходы внутри корпоративного домена
`yandex-team.ru` и его поддоменов, включая вложенные страницы Passport. Сохраняются
проверки TLS, точного OAuth callback, state и совпадения владельца Mac с аккаунтом.
Диагностика Royal содержит только хост, класс маршрута и числовой код; секретные
параметры адреса и токены не записываются.

Живая проверка исправила прежний вывод RC9: одного постоянного self-signed
сертификата недостаточно для доступа к старым записям login Keychain из новой
сборки. RC10 выносит операции в отдельный неизменяемый подписанный компонент.
Обычное обновление меняет приложение, но копирует компонент хранения без
изменения байтов или подписи. Доступ к нему идёт через локальный XPC с проверкой
подписи клиента и сервера; новый сетевой порт не открывается.

Для чтения старой записи macOS может потребовать разовое разрешение через
RP → «Подключить защищённое хранилище…». Миграция сохраняет старые записи и
проверяет новую копию до использования. При недоступности хранилища приложение
не создаёт пустую регистрацию. Выход оставляет устойчивый маркер удаления, чтобы
legacy-сессия не восстановилась. Требования MFA и отзыв корпоративной сессии
остаются под контролем провайдера.

Установщик обновляет регистрацию LaunchAgent после замены приложения. Если
автозапуск выключен, но процесс ещё работает, обновление перезапускает его и
сохраняет выключенный автозапуск. Штатное удаление включает новый компонент;
обычное удаление сохраняет данные, `--remove-data` удаляет пространства Keychain
Robopark. Данные сайта в системном браузере удаляются через настройки браузера.

Комплект: OTA для тестового Khadas, однофайловый Mac `.command`, `.pkg` и
подписанный каталог автоматических обновлений. Существующая служба обновления
устанавливает проверенный пакет без повторного пароля администратора. Ручная
установка системных компонентов требует штатных прав macOS. Apple Developer ID
и notarization отсутствуют; тестовая подпись не заменяет проверку Apple.
