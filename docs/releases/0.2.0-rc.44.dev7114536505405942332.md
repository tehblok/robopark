# Robopark 0.2.0-rc.44.dev7114536505405942332 — AGX Orin test

Тестовый prerelease для чистой установки на GEACX1 AGX Orin из проверенного
recovery-набора. Сохраняет функциональность RC43 и схему PostgreSQL
`0062_notification_retention_idx`; добавляет проверку платформы, подготовку
зависимостей с защитой vendor BSP и отдельный модуль TensorRT/DLA/JPEG.

В install-архиве находятся `INSTALL-AGX.sh`, проверка платформы, инструкции по
NVMe, ускорению и переносу CMS-копии Khadas. Данные пользователей, секреты,
персональный preset и веса моделей в архив не включены. Восстановление данных
выполняется отдельно с исходным `SECRET_KEY`; настройки хранилища и служб AGX
остаются от новой установки.

## Установка

Скачать `robopark-0.2.0-rc.44.dev7114536505405942332-install.tar.gz` и соседний
файл `.sha256`, проверить контрольную сумму и распаковать архив в отдельный
каталог на AGX. Далее выполнять `AGX-README-RU.md`: проверка
`./INSTALL-AGX.sh check`, подготовка NVMe, затем `./INSTALL-AGX.sh install`.
Для повторения только подготовки ускорителя предусмотрен `./INSTALL-AGX.sh setup`.
Нужен интернет для зависимостей и сборки контейнеров.

SHA-256 установочного архива:
`7b0d875e053ff30da07d20e0c576870b172a56d9e418b536a7e333bd70a10bf5`.

## Проверки и ограничения

- 1473 host-теста прошли; Ruff, shell syntax, OTA verify и контрольные суммы — успешно.
- Две независимые сборки дали одинаковый SHA-256. Публикуется этот же архив без пересборки.
- История исходной сборки сохранена в `SOURCE-SNAPSHOT.json`; версии исходников тега
  синхронизированы с файлами уже проверенного payload. `git_sha` внутри OTA указывает
  исходный базовый коммит снимка, а не позднее созданный коммит публикации.
- Установка на физическом AGX, ARM64 Docker build и аппаратные GPU/DLA/JPEG smoke-тесты
  ещё не выполнены. Производительность не измерена.
- Accelerator доступен как отдельный сервис и CLI; API/worker пока его не используют.
- Моделей нет, Edge LLM выключен. DLA требует совместимого runtime и отдельной проверки
  на целевом устройстве; установка не заменяет vendor BSP ради DLA.
- Это тестовый установочный пакет, не offline-образ ОС и не стабильный выпуск.
