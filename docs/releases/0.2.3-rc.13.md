# Robopark 0.2.3-rc.13 — Automatic corporate sign-in completion

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable 0.2.2 не обновляются. OTA совместим с RC9–RC12.

Исправлено зависание корпоративного входа на странице «Токен доступа».
Mac автоматически принимает полный токен со страницы выдачи корпоративного
OAuth, проверяет совпадение аккаунта с владельцем Mac и сохраняет сессию.
Копировать токен или вставлять его в Robopark не нужно. Поддерживаются также
возврат с OAuth fragment на корневую страницу и прежний verification_code.

После входа приложение использует OAuth для Tracker и проверки доступности
Inventory, а общую Passport-сессию — для подключения Emergency. Состояния
сервисов проверяются отдельно: наличие токена не означает наличие прав во
всех системах. Пароли, MFA и буфер обмена не читаются; секреты не попадают в
диагностику и не отправляются на сервер Robopark или другие Mac.

Если страница выдаёт токен без срока действия, приложение не придумывает срок:
оно сохраняет токен и повторно проверяет аккаунт перед использованием после
истечения интервала проверки. Известный срок действия по-прежнему учитывается.
Временный сетевой сбой не удаляет сохранённый вход; отзыв токена, отказ в
доступе и смена владельца блокируют его использование.

Сохраняются локальное хранилище RC12, автоматическое обновление установленного
Mac без повторного Keychain-запроса и штатное подтверждение серверного OTA.
Для завершения новой корпоративной авторизации пользователь проходит вход/MFA
в окне приложения; права корпоративных систем не изменяются.

Комплект содержит OTA для тестового Khadas/AGX, Mac `.command`/`.pkg`,
подписанный каталог обновления и документацию. Фактическая проверка личного
корпоративного входа после обновления отмечается отдельно от сборочных тестов.
