# Robopark 0.2.0-rc.35

Исправляет зависание вкладки «Работа → Проверка» при медленном или недоступном
Emergency. Обновление объекта текущего пользователя больше не сбрасывает
запущенный запрос и уже показанную ошибку. Изменение аккаунта или прав
по-прежнему отменяет право старого ответа менять интерфейс.

Таймаут ожидания общего запроса Emergency возвращается как ошибка интеграции
с возможностью повторить проверку. При передаче ошибки между процессами
сохраняется различие между недоступностью сервиса и отклонёнными cookies.
Сетевой сбой не помечает cookies как неверные.

Включено исправление подготовки AI bridge при OTA из
[разбора сбоя rc.34](../reviews/2026-10-07-ota-rc34-recovery.md).
Для обновления старым consumer нужна описанная там подготовка службы; на
рабочем Khadas она уже выполнена. Формат OTA v1 и схема БД 0059 сохранены,
rc.34 добавлена в список совместимых исходных версий.

Этот выпуск не создаёт корпоративный VPN и не заменяет настройку доступа
хоста к Emergency. При диагностике 7 октября ping проходил, но HTTPS к
указанному API не соединялся с хоста и контейнера. Получение живых данных
требует рабочего HTTPS-доступа с хоста.

ИИ на Khadas остаётся выключенным. Восьмичасовой тест не проводится.
