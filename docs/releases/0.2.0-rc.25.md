# Robopark 0.2.0-rc.25

Подготовка и поиск ремонтных знаний для локального помощника на AGX Orin.

- Конвертер исключает пустые ключи, структурные индексы, дубли и служебную
  переписку; сохраняет инструкции с последовательностью страниц и отмечает
  отсутствующий визуальный контекст.
- Таблицы XLSX/XLSM/XLS/CSV читаются без запуска макросов, формул и внешних
  подключений. Заголовки и значения превращаются в связанные справочные записи.
- Карточки ремонта отделяют симптомы, записанные действия и наблюдения.
  Закрытие задачи не становится доказательством успешности ремонта.
- Поиск учитывает компоненту, код и положение детали. Точные ограничения
  применяются до ограничения кандидатов; короткие коды и варианты разделителя
  поддерживаются без перестройки старого индекса. Инструкции и справочники
  получают приоритет для соответствующих вопросов.
- Контекст помощника ограничен вместе с источниками, историей и текущим тикетом.
  Частный корпус остаётся вне публичного Git и OTA.

Схема БД остаётся `0057_local_ai`; OTA hash-only v1 и восстановление снимком
сохранены. Импорт v2 не удаляет пользовательские материалы и не активирует
ранее удалённые записи автоматически. Старый seed v1 не следует смешивать с v2.
Khadas не устанавливает модель. Качество ответов Bonsai и производительность
на физическом GEACX1 ещё требуют приёмки; восьмичасовой тест не выполнялся.

Инструкция: [локальный помощник](../runbooks/local-ai.md).
