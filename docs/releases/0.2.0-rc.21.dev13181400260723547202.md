# Robopark 0.2.0-rc.21

Пакет `0.2.0-rc.21.dev13181400260723547202` исправляет определение IP клиента
за Tuna: nginx использует последний недоверенный адрес в цепочке, сохраняя
точный список доверенных прокси. Это устраняет объединение клиентов под
loopback-адресом в лимитах входа.

В поставку входят накопленные изменения интерфейса, PostgreSQL, резервного
копирования и OTA, а также терминал владельца: обычный Unix-пользователь и
отдельный root с паролем, свежим TOTP и ограничением времени.

## Установка

Готовый `.ota` доступен в GitHub Release. Команда в корневом README проверяет
полный SHA-256 файла до запуска штатного меню. Чистая установка защищена от
перезаписи существующих данных. Токены и пароли вводятся интерактивно.

SHA-256: `eb2168458af4a6588c49f0f7100931bd690845bfff58ac5f69b2668014002092`.
Формат OTA: 1, hash-only. Миграция: `0056_host_terminal`.
Обновление разрешено с `0.2.0-rc.20.dev11411368079194000089`.

## Происхождение пакета

Опубликованы неизменённые байты пакета, проверенного и установленного до
публикации исходников в main. Он собран из рабочего дерева на базе Git
`9b70a2096170cda472d0a6763a749cc621c1893a`; этот SHA в manifest обозначает базу
снимка, а не последующий коммит публикации. SOURCE-SNAPSHOT.json в Release
содержит хэш выбранных исходников и точную совместимость.

Тег публикации включает соответствующие исходники, тесты и документацию.
Повторная сборка из этого тега не обещает исходный SHA-256: метаданные Git и
документация изменились при публикации. Существующий asset не пересобирается
и не заменяется другим содержимым под тем же номером.

## Проверено

На рабочем хосте установка завершена, версия/build подтверждены, доступен
откат к rc.20. Публичный запрос через Tuna теперь сохраняет внешний IP.
Обычный и root-терминалы прошли проверку на предшествующем rc.20; в rc.21 их
runtime не менялся, доступность после обновления подтверждена.

Отдельный тест настоящего nginx проверяет доверенную цепочку Tuna и отказ
недоверенному контейнеру в подстановке IP. Длительный восьмичасовой прогон
не выполнялся. Этот RC не является обещанием отсутствия всех ошибок или
защиты внешней инфраструктуры туннеля от объёмных DDoS-атак.
