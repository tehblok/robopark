# Robopark 0.2.0-rc.23

Подготовка измерений производительности AGX Orin и ограниченного кэширования.
Схемы `nvme-root` и `emmc-nvme-data` из rc.22 сохраняются.

- Снимки частот CPU/GPU, доступных температур и ожидания памяти/I/O,
  сигнала Wi-Fi и счётчиков ошибок поступают в «Систему» через существующий
  host bridge. Отсутствующие датчики не объявляются исправными или нулевыми.
- Кэш валидаторов браузера ограничен по размеру, числу записей и времени жизни.
  Поздние ответы перекрывающихся запросов не возвращают кэш к старому состоянию.
- JS/CSS/SVG предварительно сжимаются при сборке; nginx отдаёт готовый gzip
  поддерживающим его клиентам, сохраняя исходные файлы и правила обновления PWA.
- Изолированный стенд проверяет 2 или 4 процесса API и фактические настройки
  PostgreSQL соответствующего ресурсного профиля.
- Исправлена несовместимость теста потокового чтения ZIP со стандартной
  библиотекой Python 3.12; отрицательная проверка чтения большого архива
  целиком остаётся обязательной.

Настройки питания, частоты, JetPack/BSP и параметры production-БД автоматически
не меняются. GPU-обработка изображений и OCR не добавлены. Этот кандидат ещё
не проверен на физическом GEACX1. Восьмичасовой тест не проводится.

Миграционная версия `0056_host_terminal`, OTA hash-only v1 и авторизация
сохранены. Поддерживаются точные исходные версии из `deploy/release-metadata.json`,
включая локальный кандидат rc.22.

Инструкция: [производительность GEACX1](../runbooks/geacx1-performance.md).
