# Robopark 0.2.0-rc.41

В почасовые PNG и связанные сообщения возвращены открытые задачи с тегом
`donor`. Фильтр принадлежности парку, типы repair/service/calibration и
приоритет blocker сохранены. Раньше исключение donor убирало из отчёта
«Север» три действующие задачи, оставляя четыре вместо семи.

Рабочее время ремонта 09:00–21:00 считается по часовому поясу парка, включая
текущий период очереди и подтверждённые периоды из истории. Ночное время
не учитывается. Часы простоя по-прежнему считаются как календарная длительность.
Порог SLA и оформление PNG сохранены.

Для Тюмени, Астаны и Алматы на действующем хосте настраивается местное время
UTC+5 (МСК+2) для парков и рассылок. Созвоны сохраняют явное Europe/Moscow.
Эта настройка хранится в БД: обновление не подменяет пользовательские
настройки других установок и не переименовывает парки.

Уведомления сайта автоматически исчезают через 24 часа после создания,
включая непрочитанные. Старые записи очищаются фоновым процессом;
список и счётчик не показывают просроченные уведомления до его запуска.

В управлении Telegram добавлены общий список заданий доступных парков,
фильтры по типу и поиск. Изменения из бота обновляются автоматически,
несохранённый ввод не затирается. Архив импорта отделён от текущего состояния.
В боте появились кнопки настройки ссылок, дней, часового пояса, чередования,
Tracker-тега и расписания. Почасовое окно сохраняется атомарно; список
заданий имеет страницы. Новые Zoom-задания используют московское время.

Формат OTA v1 и ускорение поиска из rc.40 сохранены. Миграция 0062
добавляет индекс для порционной очистки уведомлений.
