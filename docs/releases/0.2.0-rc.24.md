# Robopark 0.2.0-rc.24

Локальный помощник для механиков, операторов и администраторов на AGX Orin.

- Чат с контекстом доступного тикета, источниками, отменой и сохранённой очередью.
- Встроенная база знаний: поиск по смысловым терминам и кодам, импорт, правка,
  уровни доверия, изоляция парков, удаление без повторного автодобавления.
- Опыт ремонта пополняется после одобрения оператором и подтверждённого закрытия
  в Tracker. Модель не заменяет обязательные поля, фотографии и проверку оператора.
- API-коннекторы с шифрованием токенов, скрипты в изолированном контейнере,
  тестирование, явное включение, отключение, удаление и очистка истории правил.
- Установщик допускает модель только на P3701/Tegra234 с минимум 24 GiB,
  подтверждённым NVMe и CUDA. Prism runtime и веса Bonsai закреплены по ревизии
  и SHA256. Хост проверяет GPU и пробный ответ перед готовностью.
- Учитываются обе схемы хранения: NVMe root и eMMC OS + NVMe data.
  Khadas работает без установки модели. Частный корпус не публикуется в Git/OTA.

Добавлены таблицы `0057_local_ai`; существующие данные не переписываются.
OTA hash-only v1 сохранён. Восстановление — из согласованного снимка.
Проверка на физическом GEACX1 пока не выполнена; восьмичасовой тест исключён.

Инструкция: [локальный помощник](../runbooks/local-ai.md).
