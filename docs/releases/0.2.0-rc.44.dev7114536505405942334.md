# Robopark RC44 — локальный Mac-клиент, офлайн и общий пул

Версия `0.2.0-rc.44.dev7114536505405942334` продолжает предыдущий Mac-пилот.
Установщик для Apple Silicon/macOS 13+ теперь включает полный рабочий
интерфейс. Он открывается с локального HTTP-сервиса на loopback и не зависит
от наличия удалённого сайта с визуалом. Серверный API и каталог обновлений
остаются на подписанном HTTPS-origin; новых Tuna TCP-портов не требуется.

После входа в одобренный аккаунт с разрешением Emergency Mac автоматически
регистрируется в пуле. Устройства доверенные по умолчанию; отзыв, активность
владельца, роли и VIN/park scope сохраняются. Потерянный ответ регистрации
не расходует новый слот при повторе с сохранённым ключом. Локальный logout
останавливает агент даже при заблокированном Keychain; отложенный серверный
отзыв завершается при следующем доступном входе владельца.

Офлайн-набор подготавливается в центре синхронизации: до 12 доступных парков,
50 задач и 100 роботов на парк. Подготовленные снимки сохраняются до 72 часов,
после 12 часов видна их давность. Поддерживаемые действия, фотографии и
черновики используют локальную очередь и прежние серверные idempotency,
проверки прав и конфликты. Desktop-хранилища защищены AES-GCM с ключом из
Keychain; управляющие поля очереди также проверяются на целостность.

Брокер распределяет чтения Emergency между готовыми Mac с учётом задержки,
слотов, загрузки, питания и давности участия. Объединение одинаковых запросов,
общий трёхсекундный VIN-cache, ограниченные очереди и общий лимит 8 чтений/с
сдерживают нагрузку на корпоративную ручку. Проверки готовности ограничены
2/с. Mac сжимает ответы raw DEFLATE; сервер проверяет размер, структуру,
VIN и права до выдачи результата. Пауза, разрыв связи и просроченные ответы
исключаются из выполнения. Метрики пула доступны в центре синхронизации.

На локальном синтетическом стенде проверяются 100 настоящих WS-соединений,
параллельные RPC, распределение, cache/singleflight, pause/disconnect и
повреждённые ответы. Это не аппаратная приёмка ста ноутбуков. Физические
Khadas/AGX Orin, корпоративный SSO и установочный/обновляющий цикл macOS
нужно подтвердить после предоставления доступа. В комплекте один `.ota`
для поддерживаемых ARM64-систем обоих серверов и один macOS `.pkg`.

Developer ID и notarization на машине сборки недоступны: тестовый pkg
не подписан Apple. App имеет ad-hoc подпись, каталог и deployment profile —
Ed25519. Шифрование HTTPS/WSS не скрывает содержимое от TLS termination.
GPU/OCR/произвольные вычисления и прямая peer-передача файлов не включены;
измерения реальной разгрузки серверного Wi-Fi ещё предстоят.

Инструкция: [установка и сценарии стенда](../runbooks/test-release.md).
Архитектура: [Mac offline и распределённый пул](../architecture/2026-10-13-macos-offline-pool.md).
