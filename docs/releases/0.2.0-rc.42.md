# Robopark 0.2.0-rc.42

Сайт и Telegram используют один серверный поиск задач робота, общую
нормализацию, правила видимости и кэш Tracker. Свежая полная выборка
реестра используется без повторного обращения к Tracker.

Открытые ремонт, обслуживание и калибровка показываются независимо от
приоритета. Задачи с непарковыми тегами (например, SC) доступны, если
открытая задача того же робота в той же очереди подтверждает его связь
с доступным парком. Задачи другого известного парка этим правилом
не открываются. Карточка, комментарии и лента связанных задач доступны
для чтения; права изменения не расширяются.

Исправлено чтение многозначного поля rover. Поиск поддерживает номер,
префикс a и полный YASADR, включая задачи без номера в заголовке.
В интерфейсе раздел называется задачами ремонта, сервиса и калибровки.

Доноры остаются в почасовых PNG всех парков. Формат OTA v1 и текущая
схема БД сохранены; новых миграций нет.
