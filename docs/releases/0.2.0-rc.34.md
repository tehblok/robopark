# Robopark 0.2.0-rc.34

Выпуск для обновления Khadas и подготовки будущего AGX Orin. Сохраняет OTA v1,
обновление с rc.33 и прежних явно перечисленных версий, схему БД 0059 и
автоматический rollback при неуспешном обновлении.

Помощник подготовлен под обученную модель владельца: до её подключения
генерация выключена, базовые веса не скачиваются. Для AGX Orin подготовлены
подключение GGUF, четыре слота выполнения и ограниченная очередь запросов.
TensorRT остаётся будущим вариантом, его загрузка и исполнение ещё не реализованы.
Khadas не устанавливает локальный ИИ. Подготовленный корпус знаний и исходные
импорты удалены из текущего проекта; установщик больше их не загружает.

Инструменты помощника используют действующие права пользователя и свежие
проверки доступа. Закрытие и удаление требуют подтверждения; секреты и
защищённые операции хоста остаются в штатных интерактивных формах.

Исправления ресурсов и жизненного цикла:

- На Khadas chat workers больше не опрашивают очередь БД каждые 250 мс.
  Восстановление прерванных заданий при старте сохраняется; на неподдерживаемом
  хосте остаётся только проверка маленького файла возможностей раз в две секунды.
- Отключение потребителя кэша отзывает право позднего ответа заполнять кэш.
- Помощник отменяет запросы создания диалога и отправки сообщения при уходе
  со страницы. Уже принятое сервером задание сохраняется и доступно после возврата.
- Загрузка каталога парков отменяется при размонтировании провайдера.
- Брошенные соединения с локальным AI broker освобождают обработчики и файловые
  дескрипторы по таймауту. Это не сокращает отдельный таймаут генерации.

PWA сохраняет отдельные версии ресурсов, ограниченные кэши и IndexedDB,
безопасную активацию service worker и защиту неотправленных действий/вложений.
API-ответы и вложения не попадают в service worker cache.

Проверки и ограничения описаны в
[отчёте об аудите](../reviews/2026-10-06-cache-pwa-rc34.md).

Границы проверки: модель пока не предоставлена; качество, скорость и нагрузка
реальной модели на AGX Orin не измерялись. Восьмичасовой тест не проводится
по решению владельца. Этот пакет не устанавливается на рабочий хост автоматически.
