# Robopark 0.2.0-rc.40

Поиск робота в Telegram использует свежую полную выборку задач реестра,
если она уже загружена сайтом. Если её нет, запрос объединяет разрешённые
парки одной очереди: вместо последовательного обращения по каждому парку
достаточно одного запроса. При достижении лимита сохраняется прежний обход
парков, чтобы не терять задачи за частичными совпадениями номера.

Повторные и одновременные поиски используют общий кэш на 20 секунд,
ограниченный по числу записей и памяти. Изменение задачи и смена токена
сбрасывают результат. Просроченные ответы при ошибке Tracker не выдаются.
Права пользователя проверяются при каждом запросе, включая попадание в кэш;
очередь, тег парка и точный номер робота проверяются вместе.

Сохранены открытые ремонты, история, перемещения, ЗИП, приоритеты, сортировка
и оформление карточек. Неполные аналитические снимки не подменяют полный
список задач. Формат OTA v1 и схема БД 0061 не меняются; исправление
последовательности OTA из rc.39 сохранено. ИИ на Khadas не включается.
