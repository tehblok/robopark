# Robopark 0.2.3-rc.4 — исправление чистой установки Mac

Тестовый prerelease для `https://roboparktest.ru.tuna.am`. Production и Latest
stable `0.2.2` не переключаются. Функции распределённого пула и корпоративных
Mac-шлюзов из [rc.3](0.2.3-rc.3.md) сохранены.

Исправлена блокировка установки при отсутствующем `/Applications/Robopark.app`.
`PlistBuddy` выводил сообщение `File Doesn't Exist, Will Create` в stdout,
а установщик принимал его за неизвестную установленную версию. Исправлены
обе проверки: во внешнем `.command` и в `preinstall` внутри `.pkg`.

Теперь отсутствующее приложение допускает чистую установку и повторную
установку после удаления. Оставшиеся квитанция пакета и LaunchAgent не считаются
установленной версией приложения. Существующий повреждённый bundle, ошибка
чтения версии, пустая/неизвестная версия и символическая ссылка останавливают
установку. Защита от понижения более новой версии сохранена.

Используйте новый **Robopark-0.2.3-rc.4-arm64.command** целиком. Ручная правка
старого `.command` не исправляет вложенный пакет. Если двойной щелчок блокируется,
запустите файл через `bash` в Terminal. Тестовая сборка без Apple Developer ID
и notarization; защита macOS не отключается.

Проверка дефекта выполняется реальным `PlistBuddy` и shell-кодом обоих
установщиков на временных путях: отсутствие приложения, остатки после удаления,
обновление, повторная установка, downgrade, повреждённый plist, отсутствие
ключа, пустая версия, symlink и неуспешное чтение. Системные пути, службы и
приложение на машине сборки не изменяются.

Выпуск включает обновлённые OTA и однофайловый установщик Khadas с новым Mac
пакетом и подписанным test/rc-каталогом. Это позволяет тестовому серверу
раздавать исправленное приложение. Новых миграций БД нет. Физическая установка
на Khadas/Mac, личный корпоративный SSO и несколько Mac в разных корпоративных
сетях остаются отдельной полевой приёмкой. Ограничения rc.3 сохраняются:
корпоративные ответы проходят через сервер; прямой WebRTC используется для фото.

Бывший production Khadas включать без интернета до подтверждённого карантина
установщиком. Инструкции и схемы находятся в `START-HERE.md` и архиве Khadas.
Результаты проверок — в `verification.json`, хеши — в `SHA256SUMS`.
