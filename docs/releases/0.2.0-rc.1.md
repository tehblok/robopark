## Обновление

Установки старше `0.1.45` сначала проходят через bridge `0.1.45`. Неизвестная
схема базы отклоняется до изменения данных. Для необратимого пути восстановление
выполняется из PostgreSQL snapshot.

## Известные ограничения

Полная платформенная приёмка на ARM-хосте, нагрузочный прогон, soak и проверка
установщика остаются отдельными разрешаемыми воротами. До них версия не считается
готовой к публикации в stable.

## Evidence

Source SHA и digest артефакта будут добавлены только после разрешённой полной
приёмки и создания неизменяемого артефакта.
