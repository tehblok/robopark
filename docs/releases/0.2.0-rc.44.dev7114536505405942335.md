# Robopark RC44 — исправление OTA с RC43

Версия `0.2.0-rc.44.dev7114536505405942335` исправляет ошибку упаковки
предыдущего тестового выпуска. При создании временного Git-снимка правило
`data/` повторно исключало уже отслеживаемые исходники `EntityRow.tsx` и
`MetricCard.tsx`. На Khadas сборка web останавливалась с TS2307 и
`ota_stage_failed` до снимка БД и переключения приложения.

Снимок теперь сохраняет точный состав исходного Git-индекса, включая
отслеживаемые файлы под ignore-правилами. Неотслеживаемые секреты в него
не копируются. Регрессионная проверка читает содержимое готового OTA.

Установленный обновлятор RC43 также не знает о новом сервисе
`emergency-bridge` и исключает его из Compose. Новый выпуск подключает
отдельную дополнительную конфигурацию, используя уже закреплённый образ API.
Основной Compose и ссылка на него не меняются. При наличии bridge в основном
Compose дополнительный файл становится нейтральным. Конфигурация для отката сохраняется;
ручной патч установленного RC43 не требуется. Существующее значение
`EMERGENCY_BRIDGE_ENABLED` не меняется.

Функции локального Mac-клиента, офлайн-очереди, шифрования и пула устройств
описаны в [предыдущем выпуске](0.2.0-rc.44.dev7114536505405942334.md).
Mac pkg остаётся тестовым: Developer ID и Apple notarization отсутствуют.
