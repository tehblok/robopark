## Изменения

- Исправлен выбор получателей уведомлений на границе локальной полуночи.
- Быстрые изменения фильтров аналитики сохраняются совместно.
- Офлайн-перезапуск не ждёт сетевого таймаута; возврат сети проверяет сессию
  и отменяет устаревшее восстановление, включая изменение прав доступа.
- Одновременные запросы на обновление PWA согласуются между вкладками;
  совместимость со старыми открытыми вкладками сохраняется.
- Обновлены закреплённые зависимости API, интерфейса и бота; установка бота
  проверяет хэши всех зависимостей.
- Исправлены владельцы запросов и освобождение ресурсов интерфейса; устранены
  предупреждения статического анализа и восемь недостижимых обёрток страниц.
- Сохранены прежние URL, область доступа пользователя и парка, PWA-данные.
- Сборщик обновлений поддерживает переход на stable и последующие версии.
- Усилены проверки Origin, ограничения входа и API, квоты загрузок фото и
  проверка прав при офлайн-отправке. API и worker запускаются без Linux
  capabilities и без возможности повышения привилегий.
- Активация PWA ожидает готовности нового worker; отменённая или оборванная
  активация освобождает локальные записи и не перезагружает новую работу.
- Сборщик отклоняет повторные revision ID, исполняемые метаданные новых
  миграций и изменение исходников во время подготовки пакета.
- Настройки бота корректно различают загрузку, ошибку чтения и неизвестное
  состояние токена; выбор архива локализован.

## Совместимость и проверка

Точный список совместимости находится в `deploy/release-metadata.json` и формируется
из проверенных архивов. Для терминала допустим переход с foundation
`0.2.0-rc.17.dev16437318597787721811`, который заранее устанавливается на rc.16.
Выпущенные миграции остаются байт-в-байт прежними. Новая `0056_host_terminal`
добавляет сессии, tickets и lifecycle audit без команд/вывода; переход с
`0055_media_upload_park` сохраняет данные. Перед заменой версии выполняется
штатная проверка OTA; защита TOTP и откат через snapshot сохраняются.

Проверки браузеров выполняются в закреплённом контейнере Playwright.
Они не заменяют испытания камеры, печати и установленной PWA на физических
устройствах. Фактические результаты длительных прогонов и развёртывания
фиксируются отдельно; незавершённый прогон не считается успешным.

- Исправлено восстановление после лимита OTA: владелец видит и удаляет свои
  неиспользуемые загрузки, в том числе старые несовместимые пакеты, без локального
  файла. Проверка совместимости установки и защита активных операций сохранены.
- Убрана анимация фона кнопок, временно нарушавшая контраст после сохранения.

## Терминал royal

Добавлены ordinary/root профили терминала с паролем/TOTP, сроками действия, отзывом и ограниченными буферами. Миграция `0056_host_terminal` добавляет lifecycle сессий без записи команд. Для доставки терминала с rc.16 требуется сначала foundation `rc.17.dev16437318597787721811`. Фактическая приёмка и установка указаны в [отчёте](../reviews/2026-10-02-royal-terminal.md); этот текст не подтверждает прохождение неисполненных gates.
