Production-выпуск из AGX RC44 `0.2.0-rc.44.dev7114536505405942332`.
Исправляет остановки установки на GEACX1 AGX Orin после восстановления Khadas.

## Исправления

- До первого Docker Compose создаётся `/run/robopark-ai`; systemd повторяет
  создание при старте после перезагрузки. Наличие модели для этого не требуется.
- AI broker получает `/var/lib/robopark/ai` до настройки systemd namespace.
  Существующие права и владельцы AI-файлов сохраняются; установка моделей
  не требуется.
  Это устраняет `226/NAMESPACE` при первом OTA с восстановленного RC44.
- Установщик accelerator создаёт группу GID 10001, `video` и `render`
  до пользователя и запуска службы. Публичные каталоги кода доступны службе
  при запуске установщика с `umask 077`.
- Для проверенного NVIDIA postinst r39.2.1 используется штатный временный
  marker пропуска boot firmware. Установщик конфигурирует только ожидающие
  `nvidia-l4t-bootloader` и `nvidia-l4t-bsp`, сохраняет загрузчик и удаляет
  только созданный им marker. Неизвестный postinst не обходится автоматически.
- `INSTALL-AGX.sh --operator-confirmed-platform install|setup|check` принимает
  подтверждённую оператором платформу. Без флага проверяется recovery identity.
  Отчёт сохраняет фактический L4T и расхождения с reference recovery.
- Публичный сборщик сохраняет stable-версию и SHA исходного коммита,
  включает NVIDIA helper и исключает персональный preset, приватные ключи
  и данные установленной системы.

- Tracker SDK распознаёт ссылки `/v2/offices/{id}` внутри ответов API.
  Сохраняются поля связанных ресурсов и предупреждения о прочих неизвестных
  коллекциях; дополнительных запросов к Tracker не добавлено.

## Установка и обновление

`robopark-0.2.0-install.tar.gz` — публичный установочный комплект для чистого
хоста; `robopark-0.2.0.ota` — обновление через штатное меню/интерфейс Robopark.
Контрольные суммы находятся в `SHA256SUMS`. Инструкция AGX включена в архив.
Работающий восстановленный хост обновляется через OTA, не через clean install.
Отдельный accelerator не управляется OTA: после обновления приложения
для применения его исправлений нужно из распакованного комплекта 0.2.0 выполнить
`./INSTALL-AGX.sh --operator-confirmed-platform setup`. На проверенном AGX
эти исправления уже применены закрытым one-click комплектом.
Схема БД остаётся `0062_notification_retention_idx`; RC44 …2332 добавлен в
список совместимых исходных версий. Исторический RC44 не перезаписывается.

Архив `khadas-20261014T071500Z`, доменные токены, ключи и закрытый one-click
комплект распространяются отдельно. Они не загружаются в публичный GitHub.
При переносе исходный Khadas должен оставаться выключенным.

## Проверка на AGX, 14 октября 2026

По SSH проверен восстановленный RC44 с применёнными исправлениями установки:
AGX Orin 32 GB, Ubuntu 24.04, L4T 39.2.1, ядро 6.8.12-1021-tegra.
Все пять контейнеров (PostgreSQL, API, web, worker, Telegram) healthy;
перезапусков и OOM нет. Локальный и публичный readiness возвращают HTTP 200,
БД и интеграции готовы. Сервисы HTTPS, SSH, accelerator и terminal broker
активны; failed systemd units отсутствуют, `dpkg --audit` пуст.
Установщик подтвердил восстановление 102 таблиц и 53 748 строк.

В ограниченном просмотре журналов обнаружены предупреждения Tracker SDK
`Unrecognized collection` для offices. Историческая ошибка watchdog не
повторяется в последних проверках. Предупреждения offices исправлены в этом выпуске регистрацией соответствующей
коллекции SDK; повторение watchdog проверяется после обновления. Проверка здоровья не заменяет все пользовательские сценарии.

Модели не включены, accelerator сообщает `model_ready=false`. GPU/DLA
inference, качество локального ИИ и производительность моделей не принимались.
Результат установки финального артефакта и проверки хоста публикуется
в `VERIFICATION.json` вместе с контрольными суммами релиза.

## Локальная проверка выпуска

- Host/OTA/installer: 1490 passed, 8 skipped.
- API fast gate и дополнительные AI/campaign regressions: 127 passed.
- Tracker SDK/lifecycle/fields/collaboration: 37 passed.
- Web: TypeScript, production build, PWA assets, lint и 33 route IDs проверены.
  Из 2942 unit-тестов 2935 прошли в общем прогоне; 7 ошибок ожидания при
  параллельной нагрузке не повторились в отдельном прогоне затронутых файлов
  (281 passed, 0 failed, два workers).
- Упаковка/верификатор OTA: 84 passed.
- Регрессия подготовки AI broker и systemd units: 56 passed.
- На AGX проверены первый старт без каталога, сохранение uid/gid/mode
  существующего дерева и отказ для файла/symlink вместо каталога.
- Версии, migration head и release contract согласованы; выполнено
  независимое ревью исправлений и тестов.

Полный API-набор не заявляется пройденным: первоначальный диагностический
прогон был остановлен после ошибок записи тестовых файлов в sandbox;
все затронутые тесты повторно прошли с доступом к изолированному worktree.
Дополнительный Linux-контейнерный прогон ограничен заполненным локальным
Docker-диском; проверка работающего AGX выполняется отдельно по SSH.
