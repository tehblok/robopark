# Локальный ИИ и база знаний — rc.24

## Объём поставки

Добавлены чат для механика/оператора/администратора, контекст доступного тикета,
цитируемые источники, локальный индекс знаний, импорт, редактирование и удаление.
Промпты ролей управляются администратором поверх неизменяемых серверных правил.
Задания сохраняются в БД, поддерживают отмену и повторную проверку доступа.

Подтверждённое закрытие после успешного одобрения оператором пополняет базу
проверенным опытом ремонта. Парк сохраняется до освобождения claim; внешнее
закрытие без локального одобрения не считается подтверждённым обучающим примером.
Это RAG, а не изменение весов модели. Обязательная проверка ремонта сохраняется.

Коннекторы используют фиксированный HTTPS-домен, проверку публичного IP,
шифрование токена и отсутствие перенаправлений. Скрипты исполняются только в
ограниченном контейнере без сети. Сохранение, тестирование и включение требуют
явных действий администратора; модель выдаёт только черновики. Неопределённый
результат внешнего запроса не повторяется автоматически. Очистка истории
оставляет минимальные квитанции дедупликации.

Установка Prism/Bonsai допускается только на проверенном AGX Orin с NVMe.
Учтены оба storage layout. Службы проверяют CUDA, хэш модели и пробный ответ;
скачивание и сборка не блокируют запуск сайта. На Khadas модель не устанавливается.
Версии source/model закреплены, OTA v1 остаётся без подписи издателя.

## Начальные материалы

Приватный JSONL содержит 12 598 документов: 344 инструкции, 4 180 тикетов,
1 500 фрагментов чатов и 6 574 заметки. 4 175 Markdown-копий тикетов исключены
в пользу структурированной выгрузки. Фотографии и неподдерживаемые форматы
не интерпретировались; manifest отдельно отражает пропуски и недоступные вложения.

Проверены все записи по актуальной схеме API и SHA256 частей. Проверка известных
паттернов email, Bearer и закрытых ключей не дала совпадений; это не гарантия
полного обезличивания свободного текста. Корпус, seed и диагностические результаты
игнорируются Git и исключены из OTA. Владелец импортирует приватный JSONL через UI
с выбором парка и явным выбором доверия к инструкциям/непроверенному опыту.

## Исправления независимого ревью

Устранены неверное shared-linking при переносе нативного бинарника, блокировка
команд управления долгой установкой, потеря желаемого состояния через OTA,
устаревшая проекция при bind-mount отдельного файла, гонки отмены задания и
отключения правил. Добавлены ограничение контекста до inference, проверка
источников и прав после ответа, проверка локального одобрения перед обучением,
безопасная подстановка ключа тикета в путь коннектора и сохранение квитанций
после очистки. Исправлен UI обновления статуса фоновой установки.

## Границы проверки

Нет физического GEACX1. Нативная CUDA-сборка, доступ GPU из systemd-службы,
качество ответов Bonsai на реальных вопросах, скорость, пиковая общая память и
поведение Wi-Fi на целевой плате пока не измерены. Подмена inference в тестах
проверяет контракт, но не качество модели. Установщик не выставляет ready до
проверок на самом хосте. Это кандидат релиза, а не подтверждённая аппаратная приёмка.

На рабочий Khadas модель не развёртывалась. Восьмичасовой тест не проводился
по прямому указанию владельца. Инструкция эксплуатации —
[локальный помощник](../runbooks/local-ai.md).
