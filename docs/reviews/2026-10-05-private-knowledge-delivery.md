# Проверка полной поставки знаний

## Фактически проверено

- Полная подготовленная база: 15 595 записей; штатный API `bundle.inspect`
  проверил каждый record, размеры, SHA-256 и идентификаторы.
- 17 самостоятельных age X25519 частей: 3 536 109 801 байт ciphertext.
- После расшифровки: 22 371 файл, 4 574 183 048 байт. Все 22 271 исходный файл
  побайтно по SHA-256 совпал с оригиналами владельца. Оставшиеся файлы —
  подготовленные версии, карта происхождения, проверки и сохранённые правила.
- GitHub подтвердил digest/size всех 17 assets. Публичный manifest скачан без
  авторизации; SHA-256 `4ee91ebdb20823802184889ba958749bec55be8e067ebda6743681189a4580e2`.
- Реальная HTTPS-докачка части размером 10 554 197 байт с прерванного состояния
  прошла, итоговый SHA-256 совпал.
- Официальный age 1.3.2 проверен на macOS ARM64 и в Linux ARM64 контейнере.
  Linux-тест использовал синтетический ключ/данные, network=none, read-only root,
  cap-drop ALL. Ключ передавался через descriptor удалённого файла; именованных
  файлов ключа после операции нет.
- Полный API: **2 865 passed, 31 skipped, 1 load-test deselected**, 22 предупреждения
  зависимостей, 921.77 сек. Python 3.12, запись в тестовые каталоги разрешена.
- Полный host: **1 318 passed**, 95.05 сек, включая настоящие тесты age.
- Совместно конвертер/публичная/приватная поставка: **67 passed, 2 skipped**;
  два age-теста отдельно и в полном host запускались с настоящим бинарником.
- Целевой API importer/retrieval: **28 passed**. Host integration/OTA/clean-install:
  **192 passed** до заключительных исправлений восстановления; полный host
  выше включает эти исправления.
- Ruff новых модулей, module boundaries, tech-debt registry и migration heads
  прошли. Версия пакета — rc.33, схема БД остаётся 0059.

## Исправления по независимому чтению кода

Кэш разделён по ревизиям; расчёт места учитывает докачанные байты. Незавершённые
staging-каталоги удаляются под блокировкой. Очистка ciphertext работает и после
аварии непосредственно вслед за публикацией. Повреждённая скачанная часть
перекачивается; повреждённый установленный bundle восстанавливается в новую
директорию с атомарной сменой current и сохранением прежних исходников.
Отсутствующий исходный каталог не позволяет выпустить неполный архив.

Проверки охватывают неверный ключ, повреждение ciphertext, traversal, symlinks,
повторные пути, размеры и хэши, неполный архив и переполнение PAX-заголовков,
идемпотентность, сохранение пользовательских правок/удалений и read-only mount.

## Границы вывода

Это проверка доставки и импорта, а не доказательство правильности всех советов
ИИ. Исторические записи остаются unverified, отсутствующие вложения —
пропусками, фотографии не были автоматически распознаны. Приёмка
Bonsai/CUDA на физическом AGX не выполнена. Восьмичасовой прогон не проводился.
Качество подготовки отдельно описано в [отчёте v2](2026-10-04-knowledge-quality.md).

Рабочие пользователи, настройки интеграций и данные прежнего хоста в этот
архив не включены: для них применяется штатный backup/restore. OAuth хранилище
ноутбука и личный age identity не опубликованы.
