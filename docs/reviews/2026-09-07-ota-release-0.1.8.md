# Ревью выпуска 0.1.8

Дата: 2026-09-07. Целевой хост: Armbian 26 ARM64, 8 GiB RAM, публикация через Tuna.

## Исправленные блокирующие проблемы

- Новый `START.sh update` проверяет подпись встроенного релиза установленным доверенным ключом и запускает updater из подписанного кандидата. Поэтому исправление OTA применяется поверх 0.1.6/0.1.7 и не зависит от ошибок старого updater.
- Сборки API и web выполняются последовательно. Это уменьшает пиковое потребление памяти на ARM-хосте с 8 GiB.
- Ошибка внешней команды классифицируется по безопасным кодам: диск, сеть, память, TypeScript, ARM-зависимости или этап OTA. Полный вывод остаётся в root-only `/var/log/robopark/ota-update.log`.
- `START.sh` показывает проверку подписи, подготовку updater и текущие этапы долгого обновления.
- Таймаут `robopark-updater.service` согласован с четырёхчасовым бюджетом worker и увеличен до пяти часов. Sandbox службы получил запись только в каталог журналов Robopark.
- Диагностический ZIP содержит очищенный `update-status.json` с этапом, результатом и кодом ошибки. Секреты, сырые журналы, БД и вложения туда не попадают.
- Интерфейс переводит новые коды OTA в понятные сообщения для владельца.

## Проверенные свойства

- Обновление из нового installer поверх завершённой установки сохраняет БД, пользовательские данные, конфигурацию интеграций и Tuna.
- Повреждённый локальный архив отклоняется до изменения установленной версии.
- Неуспешная сборка, тест, smoke, миграция или health-check сохраняют рабочую версию либо выполняют предусмотренный откат.
- Installer остаётся самодостаточным, воспроизводимым и не содержит закрытого ключа подписи.
- Версии API, web, lock-файлов и корневого `VERSION` синхронизированы.

## Результаты локальных проверок

- Host/installer/OTA: полный набор тестов.
- API: Ruff, проверка форматирования и полный pytest.
- Web: lint, unit/component tests, TypeScript production build, navigation и contrast checks.
- Artifact: проверка Ed25519-подписи, SHA-256 и состава архива.

## Ограничение проверки

На macOS нет целевого systemd/Docker/Tuna-контура. Реальную длительную сборку ARM64, перезагрузку systemd и публичный HTTPS необходимо подтвердить установкой этого архива на Armbian. До этого локальные тесты доказывают логику транзакции и границы безопасности, но не состояние конкретного хоста и внешних сервисов.

## Неблокирующие наблюдения

- Oxlint оставляет существующие предупреждения о React refs/effect dependencies и разделении экспортов. Текущая сборка и 1723 web-теста проходят; предупреждения стоит закрыть отдельным изменением интерфейса после восстановления production.
- Главный JS chunk около 924 KiB до gzip. Для текущей локальной публикации это допустимо, но дальнейшее ускорение первого открытия потребует разделения маршрутов на динамические chunks.
