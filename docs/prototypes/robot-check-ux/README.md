# Проверка робота — макет на основе существующего экрана

Статус: принят как часть классического эталона 19.09.2026.

`proposal.css` сохранён как исходный макет. Его правила перенесены с ограничением
классическим режимом в `apps/web/src/app/interface/classic-robot-check.css`.
Сравнение before/proposal использует один и тот же
экран текущей локальной ветки и один набор тестовых данных, а не две разные реализации.
Before не является снимком текущего production-сайта.

Изменение композиции: общая сводка и существующее изображение робота собраны в одну
область; справа остаются реальные навигация и диагностические блоки. На телефоне четыре
ключевых показателя располагаются в одной строке, высота изображения и промежутков
уменьшена. Разделы, элементы управления и значения не удалены. Цветовая тема и фото — из проекта.

Показания и их позиции взяты из существующего visual-test примера, это не реальные
измерения и не предложение заменить пользовательскую разметку. Название «Колёса»
также унаследовано от тестового примера.

Проверено 4 сочетания: 390/1440 px × light/dark. Сняты before/proposal, проверены
отсутствие горизонтального переполнения, сохранение набора кнопок и нажатие показания.
Это проверка макета, не полная проверка рабочих сценариев.

Запуск из apps/web:

```sh
npx playwright test --config ../../docs/prototypes/robot-check-ux/playwright.config.ts
```

Изображения: `/private/tmp/robopark-ux-comparison/preview-<theme>-<width>/`.
