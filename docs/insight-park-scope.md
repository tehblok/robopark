# Обзор и аналитика доступных парков

Для ролей `admin`, `royal`, `operator` разделы `/overview` и `/analytics`
без параметра парка открываются в режиме `park=all`. В общем переключателе
парка можно выбрать «Все доступные парки» или один конкретный парк.
Прямая ссылка с числовым `park` сохраняет выбор конкретного парка.

Оператору доступны только назначенные активные парки. Админ и роял получают
список активных парков через существующий API с проверкой прав. Каждый
запрос данных по парку дополнительно проходит существующую серверную
проверку доступа. При изменении прав старые ответы не подменяют новый экран.

Общий режим показывает отдельные секции парков. Аналитика дополнительно
сравнивает показатели за одинаковый период и шаг. SLA, покрытие наблюдений
и история остаются привязаны к своему парку; задачи и доли разных парков
не складываются в потенциально недостоверный общий итог.

Выбор всех парков не стирает сохранённый индивидуальный парк рабочих
разделов. Для остальных ролей сохраняется прежний выбор одного парка.

Обзор и аналитика используют общий предел в три одновременных запроса.
Оставшиеся запросы ожидают свободного места; запросы устаревшей области
не запускаются. Аналитика сохраняет кэш в памяти на две минуты с фоновым
обновлением. Авторизационная ошибка любого текущего запроса скрывает
защищённую историю даже после ошибки другого парка.

Миграции базы и изменение API для этой функции не требуются.
