# Mac test на базе Robopark 0.2.2

Постановка владельца 14.10.2026: автономно подготовить и опубликовать только
тестовый релиз; прежний Khadas-пакет ещё не установлен. Основа — опубликованный
`v0.2.2` (`2558a8a8`), включая network/Tuna/boot recovery. Новая линия получает
версию `0.2.3-rc.1`, чтобы сохранять порядок обновлений относительно stable 0.2.2.
Production и его Latest stable не изменяются.

## Пользовательский результат

- Один Mac pkg для Apple Silicon/macOS 13+: тестовый origin
  `https://roboparktest.ru.tuna.am` встроен; пользователь входит аккаунтом
  Robopark, открывает систему, видит связь/синхронизацию и управляет автозапуском.
- Регистрация устройства автоматическая, при первом входе сохраняется владелец.
  Ключ устройства не переносится на другой аккаунт при повторной регистрации.
  Доверенные активные аккаунты не требуют отдельного approval Mac.
- Корпоративный SSO нужен при отсутствии сессии Emergency; показывается только
  действие восстановления корпоративного доступа в статусе подключения.
  Поля домена, ручного enrollment-кода и VIN не входят в обычный пользовательский
  экран. Workspace и шифрованная offline-очередь сохраняются.
- Обновления Mac устанавливаются автоматически с проверкой подписанного
  каталога, SHA-256/размера, test assignment и запретом downgrade. Root helper
  из pkg получает только фиксированный тестовый источник, не произвольные
  команды/URL/пути от пользователя. Старый работающий клиент сохраняется при
  ошибке проверки/загрузки. Пользователь видит состояние обновления.
- Граф «сервер → сотрудник → Mac» показывает online/ready/offline, владельца,
  задержку, наблюдаемую скорость ответов, загрузку и выполненную работу.
  Администраторы видят весь пул, остальные — доступный им срез.

## Распределение ресурсов

Сохраняется исходящий WSS на существующий HTTPS endpoint, без новых входящих
портов. Broker выбирает пригодные Mac по свежим heartbeat, свободным слотам,
измеренной задержке, ошибкам, ресурсам и справедливости распределения.
CPU/memory/thermal — ограниченные подсказки клиента, не полномочия доступа.
Скорость измеряется по реальному выполнению и передаче ответов, называется
скоростью ответов, а не скоростью интернет-подключения. Протухшие показатели
не выдаются за живые. Состояния 0/1/2/12/100 устройств покрываются тестами.

На Mac выполняются корпоративные чтения, сжатие ответов, подготовка медиа и
локальный интерфейс; общие cache/singleflight и ограничения устраняют повторы.
Записи и авторизация остаются централизованными. Произвольный remote shell,
передача секретов между Mac, P2P/GPU-кластер не входят в этот выпуск.
Сервер в Wi-Fi всё ещё передаёт ответы; экономия трафика подтверждается
счётчиками сжатия/кэша, не обещанием полного обхода сервера.

Приложение и helper компилируются, служебные файлы обновления принадлежат root,
секреты и локальные ключи хранятся в Keychain; каталог обновления подписан.
Это защищает от обычного изменения пакета и утечки секретов из исходников,
но не скрывает адрес сервера или доставленный веб-код от администратора Mac.
Полный контроль владельца машины нельзя устранить клиентским приложением.

## Khadas и поставка

Новый однофайловый переход RC43 → test использует проверенный OTA новой версии,
сохраняет историю/аккаунты/ключ шифрования и изолирует старые внешние полномочия,
очереди и туннели. Первый запуск Khadas без интернета, затем приглашение включить
сеть. Тестовый UUID сохраняется `d6ed3b43-c41b-4614-833e-c5ec30936ef3`.
Пакет включает новый публичный Mac profile и embedded Mac distribution assets.

Git: отдельная ветка `codex/macos-pool-022-test`, тег `v0.2.3-rc.1`, GitHub
prerelease с `make_latest=false`, installer Mac, Khadas zipapp, OTA, публичный
catalog/profile/root, SHA256SUMS и инструкция. Ни секретов, ни prod presets.
Аппаратная приёмка явно отделяется от локальных тестов/сборки.
