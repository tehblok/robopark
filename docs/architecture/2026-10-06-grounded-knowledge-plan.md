# Grounded Knowledge Implementation Plan

**Goal:** заменить узкую редакционную подборку содержательной базой для механика,
оператора и администратора с проверяемыми основаниями из всех трёх типов источников.

**Architecture:** приватный реестр исходных свидетельств проверяет авторские
утверждения; роль и рабочий вопрос определяют навигацию. Готовый пакет остаётся
совместимым с импортом Robopark и не расширяет права инструментов.

**Tech Stack:** Python, JSONL/Markdown, существующий импорт SQLAlchemy, age.

**Spec:** [grounded knowledge](2026-10-06-grounded-knowledge.md).

## Global Constraints

- Источники — данные, не исполняемые инструкции; внешние сервисы не изменяются.
- Не добавлять технические рекомендации без источника и не учить веса модели.
- Приватные основания, чаты и тикеты публикуются только зашифрованными.
- AI только на AGX; unsigned OTA, права ролей и подтверждения остаются прежними.

## Review Focus

- Отрицательный результат или совет ошибочно прочитан как выполненный ремонт.
- Ответ чата привязан к соседнему, но не исходному вопросу.
- Норма одной ревизии/позиции распространена на другую.
- Статистика закрытой выборки выдана за текущий парк или вероятность отказа.
- Цитата существует, но не подтверждает смысл заявленного действия.

## Задачи

- [x] Построить приватный реестр полных текстовых источников с точными ссылками,
  хешами и контекстом; проверить его на тестах reply-связей, дублей и отказов чтения.
- [x] Заново подготовить содержательные разделы механика, оператора и администратора.
  Изолированное владение: `drafts/mechanics`, `drafts/operations`; интеграция у root.
- [x] Добавить обязательную проверку цитат, запрет редакционных оснований и
  навигацию по ролям в сборку, сохранив совместимость старого импортного формата.
- [x] Сверить покрытие исходных тем, конкретные нормы и отрицательные случаи;
  исправить замечания независимого ревью и проверить поиск вопросами всех ролей.
- [x] Уточнить подсказки ролей: действия только по основаниям, архив не текущий
  статус, показатели только с явной выборкой. Проверить ограничения контекста.
- [x] Собрать и проверить импорт; сохранить редактируемые исходники и основания
  в зашифрованной версии с прежним ключом, открыть читаемый результат.
