# Контракты модулей

API управляет предметными данными и передаёт хосту только ограниченные файловые
команды. Host-tools не импортирует приложение и самостоятельно проверяет архивы.
Web обращается к API через типизированный слой `api.ts`; прямого доступа к host state нет.

```yaml
{
  "schema": 1,
  "boundaries": [
    {"root": "apps/api/src", "forbidden_imports": ["robopark_host"]},
    {"root": "deploy/host/robopark_host", "forbidden_imports": ["robopark_api"]}
  ]
}
```

Исключений по умолчанию нет. Новая связь сначала документируется здесь и получает
контрактный тест; временный обход регистрируется как технический долг.
