# Карточка задачи и неизвестные ошибки

## Работа с задачей

Описание и комментарии поддерживают Markdown: выделение, списки, ссылки и код. Длинное описание можно раскрыть. На телефоне действия располагаются вертикально, включая ссылку в Startrek.

Текст комментария сохраняется на устройстве отдельно для пользователя и задачи. Черновик восстанавливается после перехода или перезагрузки. Успешная отправка очищает отправленную версию; новый текст, введённый до получения ответа, сохраняется. Вложения не сохраняются между перезагрузками. Если браузер запрещает localStorage или его квота исчерпана, редактор продолжает работать, но сохранение между посещениями недоступно.

При поступлении комментариев появляется уведомление с переходом к первому новому комментарию. Само обновление не прокручивает страницу. Изменения описания, названия, статуса и ответственного отмечаются уведомлением.

Время синхронизации показывает последний успешный ответ API, включая восстановление из кэша. При ошибке время не обновляется. Для задачи учитываются данные карточки и комментарии; время исходной телеметрии робота остаётся отдельным показателем.

## Разбор неизвестных ошибок

Путь: **Настройки проверки робота → Ошибки и индикация → Неизвестные ошибки**. Список доступен только одобренным администратору и владельцу (`admin`/`royal`).

При разрешённой проверке робота сервер собирает нераспознанные диагностические события. Одинаковые источник и значение группируются; перемещение элемента массива не создаёт новую запись. Счётчик — число выборочных наблюдений, максимум раз в минуту на пару робот/сигнал, а не число отдельных инцидентов. Частые повторные опросы в пределах минуты выполняют только чтение.

1. Выбрать новый сигнал и нажать **Разметить**.
2. Задать название, расшифровку, часть робота, ракурс и положение маркера.
3. Проверить пример и сохранить правило. Для длинного или переменного значения можно отредактировать шаблон и выбрать регулярное выражение.
4. При следующей проверке подходящие события получают разметку. Сохранённое правило доступно из группы «Размеченные».

**Отложить** переводит запись в «Отложенные»; она по-прежнему видна как неизвестная ошибка в проверке робота. Её можно вернуть в новые. Конфликт с разметкой другого администратора не перезаписывает уже сохранённое правило.

Хранятся только ограниченные диагностические единицы: неизвестный остаток и исходное значение, вместе до 8 КиБ. Полный ответ внешнего сервиса не сохраняется. Примеры с полями учётных данных пропускаются. Разметка проверяется по исходному значению и текущему каталогу; недостаточно совпасть с уже распознанной соседней ошибкой или искусственной оболочкой примера. Предпросмотр не пополняет список неизвестных ошибок.

Миграции 0020/0021 добавляют таблицы и исходный пример. Для записей без достоверного исходного примера разметка доступна после повторной разрешённой проверки робота.
