## Использование данных и границы

Если уже есть свежая полная выборка реестра по требуемым очередям, поиск
использует её. Старые DTO без полей классификации и неполные аналитические
снимки не считаются полноценной базой карточек. При отсутствии полной
выборки выполняется один запрос по разрешённым тегам каждой очереди.
Для комбинированной выборки, достигшей лимита 500, сохраняется старый обход
парков — частичные совпадения номера не должны вытеснить другой парк.

Отдельный кэш результатов поиска: TTL 20 секунд, до 256 записей / 8 МиБ
в памяти процесса; общий механизм LiveMerge объединяет обращения процессов
и ограничивает своё хранилище. Ключ включает хеш токена, весь запрос,
сортировку, лимиты и разрешённые очереди. Возвращается независимая копия.
Изменение задачи, списков или токена инвалидирует семейство; завершение старого
запроса после инвалидизации не восстанавливает устаревший кэш.

Права роли и назначения парков проверяются заново на каждом обращении.
Номер робота, очередь и тег одного разрешённого парка проверяются вместе.
Сохранены фильтры типа/статуса/решения и исходные приоритеты карточек.
