## Исправленные проблемы

### P1 — Важные проблемы UX

#### ✅ P1.1: Улучшена читаемость "Мои задачи" на мобильных

**Проблема:** Текст "Мои задачи" в мобильной навигации был слишком мелким (0.75rem) и трудночитаемым.

**Решение:**
- Уменьшен размер шрифта до 0.625rem для компактности
- Увеличен line-height до 1.2 для лучшей читаемости
- Добавлен `word-spacing: 100vw` для переноса слов на отдельные строки

**Файл:** `apps/web/src/app/shell/AppShell.css`

```css
.rp-shell__mobile-link[data-route-id="work-mine"] .rp-shell__nav-label {
  font-size: 0.625rem;
  line-height: 1.2;
  max-width: 3.8rem;
  text-align: center;
  text-overflow: clip;
  white-space: normal;
  word-spacing: 100vw; /* NEW: перенос слов */
}
```

**Результат:** Текст теперь отображается как "Мои" на первой строке и "задачи" на второй, что улучшает читаемость на узких экранах.

---

#### ✅ P1.2: Адаптированы фильтры работы для узких экранов

**Проблема:** Фильтры работы использовали двухколоночный layout даже на телефонах 360-390px, что приводило к тесноте.

**Решение:**
- Добавлен breakpoint @media (max-width: 599px)
- Переключение на одноколоночный layout на узких экранах

**Файл:** `apps/web/src/domains/work/work.css`

```css
@media (max-width: 599px) {
  .rp-work-filters {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

**Результат:** Фильтры теперь располагаются вертикально на телефонах, освобождая пространство.

---

#### ✅ P1.3: Унифицированы размеры шрифтов в формах

**Проблема:** Не все поля ввода использовали `font-size: 16px` для предотвращения автоматического zoom на iOS.

**Решение:**
- Добавлены явные правила для всех типов input
- Гарантирован размер 16px на мобильных устройствах

**Файл:** `apps/web/src/design-system/styles/base.css`

```css
@media (max-width: 899px) {
  input[type='text'],
  input[type='email'],
  input[type='password'],
  input[type='search'],
  input[type='tel'],
  input[type='url'],
  input[type='number'] {
    font-size: 16px;
  }
}
```

**Результат:** iOS больше не зумит страницу при фокусе на поля ввода.

---

#### ✅ P1.4: Улучшена сводка смены на очень узких экранах

**Проблема:** Метрики сводки смены (4→2 колонки) были слишком плотными на экранах <400px.

**Решение:**
- Добавлен breakpoint @media (max-width: 399px)
- Переключение на одноколоночный layout для экранов <400px

**Файл:** `apps/web/src/domains/work/work.css`

```css
@media (max-width: 399px) {
  .rp-work-summary__metrics {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

**Результат:** Метрики отображаются вертикально на самых узких телефонах (360px).
