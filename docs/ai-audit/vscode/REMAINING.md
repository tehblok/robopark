## P2 — Средний приоритет (12 проблем)

### P2.1: Кнопка "Назначить" слишком далеко от поля ввода

**Проблема:**
На широких экранах кнопка "Назначить" находится далеко справа от поля ввода логина, что затрудняет визуальную связь между элементами.

**Решение:**
```css

  max-width: 32rem; /* Ограничить ширину формы */
}
```

## Рекомендации по реализации

### Общие принципы

1. **Mobile-first:** Начинать дизайн с мобильной версии
2. **Progressive enhancement:** Базовая функциональность работает везде, улучшения добавляются постепенно
3. **Accessibility:** Каждое изменение проверять на доступность
4. **Performance:** Измерять влияние на производительность

### Процесс

1. **Дизайн:** Создать mockup/prototype
2. **Ревью:** Показать механикам для обратной связи
3. **Реализация:** Небольшие итерации с тестами
4. **Тестирование:** Unit + E2E + визуальное
5. **Деплой:** Постепенный rollout с мониторингом

### Инструменты

- **Дизайн:** Figma для mockups
- **Тестирование:** Playwright для E2E, Vitest для unit
- **Мониторинг:** Web Vitals для производительности
- **Обратная связь:** Опросы механиков после каждого релиза
