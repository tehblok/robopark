## Проблемы по приоритетам

### P1 — Важные проблемы UX

#### P1.1: Мобильная навигация "Мои задачи" для механика

**Проблема:** Пункт "Мои задачи" (`work-mine`) имеет уменьшенный шрифт на мобильном (0.75rem), что затрудняет чтение.

**Файл:** `apps/web/src/app/shell/AppShell.css:451-453`

```css
.rp-shell__mobile-link[data-route-id="work-mine"] .rp-shell__nav-label {
  font-size: 0.75rem;
  line-height: 1.1;
}
```

**Решение:** Увеличить до стандартного размера или сократить текст.

**Влияние:** Механики используют этот пункт постоянно на телефоне.

---

#### P1.2: Фильтры работы на узких экранах

**Проблема:** Фильтры работы (`rp-work-filters`) используют grid с фиксированной шириной 22rem для первой колонки, что может быть слишком широко на телефонах 360-390px.

**Файл:** `apps/web/src/domains/work/work.css:57-66`

```css
.rp-work-filters {
  grid-template-columns: minmax(0, 22rem) minmax(0, 1fr);
}
```

**Решение:** Добавить mobile breakpoint для одноколоночного layout.

---

#### P1.3: Поля ввода на мобильных устройствах

**Проблема:** Некоторые поля ввода используют `font-size: 16px` для предотвращения zoom на iOS, но это не применено везде последовательно.

**Файлы:**
- `apps/web/src/domains/robots/robots.css:7` ✅ Есть
- Другие формы — нужна проверка

**Решение:** Унифицировать размер шрифта для всех `input[type="text"]`, `input[type="search"]`, `select` на мобильных.

---

#### P1.4: Сводка смены (Work Summary) на мобильных

**Проблема:** Метрики сводки смены переключаются с 4 колонок на 2 на узких экранах, но могут быть слишком плотными на 360px.

**Файл:** `apps/web/src/domains/work/work.css:41-51`

**Решение:** Рассмотреть 1 колонку для экранов <400px.

---

#### P1.5: Inventory filters на мобильных

**Файл:** `apps/web/src/domains/inventory/inventory.css:9`

**Решение:** Уже есть @media для 599px, но нужна проверка на реальных устройствах.

### P2 — Средние улучшения

---

#### P2.2: Font sizes consistency

**Проблема:** Множество разных размеров шрифтов (0.62rem, 0.68rem, 0.72rem, 0.75rem, 0.78rem, 0.82rem, 0.85rem, 0.875rem, 0.9rem, 0.92rem, 0.95rem, 1rem, 1.1rem, 1.15rem, 1.25rem, 1.35rem, 1.45rem, 1.5rem, 1.65rem, 1.75rem, 2rem, 2.15rem, 2.25rem, 3.5rem, 4.25rem).

---

#### P2.3: Motion duration consistency

**Проблема:** Используются разные длительности анимаций.

**Токены:**

- `--rp-motion-normal: 180ms`
- `--dur-fast: 120ms`
- `--dur-base: 200ms`
- `--dur-slow: 320ms`

**Решение:** Унифицировать naming.

---

#### P2.4: Spacing scale gaps

**Проблема:** Есть пропуски в spacing scale (нет --space-5, --space-7).

**Текущие:**

- `--space-2: 8px`
- `--space-3: 12px`
- `--space-4: 16px`
- `--space-6: 24px`
- `--space-8: 32px`

**Решение:** Добавить недостающие или документировать намеренные пропуски.

---

#### P2.5: Color tokens duplication
