## Коммиты

1. **fix(ui): improve mobile UX for mechanics**

## Визуальные изменения

### Мобильная навигация (механик)

**До:**
- "Мои задачи" — мелкий шрифт 0.75rem, трудночитаемый

**После:**
- "Мои задачи" — перенос слов на две строки, лучшая читаемость

### Фильтры работы

**До:**
- Двухколоночный layout на всех экранах
- Тесно на телефонах 360-390px

**После:**
- Одноколоночный layout на экранах <600px
- Больше пространства для контента

### Формы

**До:**
- Непоследовательные размеры шрифтов
- iOS зумит страницу при фокусе

**После:**
- Все input имеют font-size: 16px на мобильных
- Нет автоматического zoom

### Сводка смены

**До:**
- 2 колонки на всех мобильных экранах
- Тесно на 360px

**После:**
- 1 колонка на экранах <400px
- Комфортное отображение
