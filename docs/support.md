# Поддержка

При обращении укажите версию, build id, SHA-256 OTA, код ошибки и скачанный
диагностический ZIP. Не присылайте пароли, cookies, env-файлы и дамп базы.

Коды `ota_hash_mismatch` и `ota_invalid_container` требуют нового файла из
доверенного канала. При `rollback_failed` прекратите повторные обновления и
следуйте [инструкции восстановления](runbooks/ota-recovery.md).
