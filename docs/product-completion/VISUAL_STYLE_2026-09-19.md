# Спокойный рабочий интерфейс

Согласованное направление: практичный инструмент для механика, без декоративных градиентов, стекла и множества вложенных карточек. Это слой оформления существующих компонентов, не переписывание бизнес-сценариев.

## Реализовано

- Общие скругления: 8 px у элементов управления, 12 px у панелей и карточек. Добавлен ранее отсутствовавший токен карточки.
- Светлый фон нейтральный; жёлтый акцент и смысловые цвета состояний сохранены. Тёмная палитра сохранена.
- Обычные панели плоские. Тени сохранены у всплывающих меню, диалогов и подписей поверх изображения, где они отделяют слои.
- Общие вкладки и вкладки диагностики используют подчёркивание вместо цветных коробок; зона нажатия остаётся не менее 44 px.
- Сводка и показания робота разделены линиями, без вложенных заливок. Позиции датчиков, фотографии и логика автоподбора не менялись.
- В задаче убраны дополнительные рамки внутри master/detail. Складские метрики объединены одной поверхностью; функции и семантические цвета остатков сохранены.

## Проверки и границы

- 12 вариантов трёх экранов: задача, проверка робота, склад × 390/1440 px × светлая/тёмная темы. Скриншоты локального стенда с тестовыми данными, не рабочего сайта.
- Компактная вёрстка и royal-маршруты: 68 passed, 2 skipped по политике доступа (до финальной локальной правки заливки телеметрии; её проверяет отдельный повтор 12 вариантов).
- Контраст существующих пар текста/фона проверен скриптом check:contrast.
- Независимое ревью обнаружило старую тень обычных панелей экрана оператора. Ошибка подтверждена двумя браузерными тестами для светлой/тёмной темы; старый `.panel` приведён к плоскому стилю без изменения теней диалогов.
- После последней правки: 14 браузерных проверок passed; полный web suite 2044 passed / 143 файла; production build успешен. Lint exit 0 с существовавшими предупреждениями.
- Бизнес-логика, API, права, интеграции, зависимости и процессы обновления не менялись. На рабочий хост пакет не устанавливался.
- Не заявляется завершение индивидуальной переработки всех старых страниц: общий стиль распространён через компоненты, три основных экрана доработаны предметно.
