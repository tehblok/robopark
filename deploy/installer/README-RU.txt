ЕДИНЫЙ УСТАНОВЩИК ROBOPARK
===========================

Установка и обновление выполняются одним файлом `robopark-<версия>.ota` на
Armbian и Ubuntu, ARM64 и AMD64. Требуется Python 3.10+.

Запуск с USB или локального диска:

    sudo python3 robopark-<версия>.ota

Меню показывается до проверок Docker, сети и установленной версии:

1. Чистая установка. Безвозвратно удаляет только данные и Docker-объекты
   Robopark, создаёт пустую PostgreSQL и первого пользователя royal.
2. Обычное обновление. Сохраняет данные, делает snapshot и автоматически
   откатывается при ошибке миграции, переключения или readiness.
3. Диагностика. Собирает безопасный архив даже при повреждённой установке.
4. Полное удаление. Удаляет только явно разрешённые объекты Robopark.
5. Выход.

Для первого перехода со старой ветки используйте чистую установку. Старые
данные, вложения, кэши и резервные копии не переносятся. Перед удалением
показывается точный список целей и запрашивается контрольная фраза.

Проверка файла без установки:

    python3 robopark-<версия>.ota verify --json

Сам файл содержит SHA-256 каждого элемента и проверяет целостность до любых
изменений. SHA-256 не подтверждает личность автора: переносите файл только по
доверенному локальному каналу. Дополнительные ключи и sidecar-файлы не нужны.

Веб-обновление выполняет royal в разделе состояния системы: браузер считает
SHA-256 локально, загружает файл частями и позволяет продолжить прерванную
загрузку. Запуск обновления требует отдельного подтверждения паролем royal.

Пароль первого royal вводится скрыто дважды. Он не передаётся в аргументах,
переменных окружения, журналах, манифесте или browser storage.
