# Архивная заметка: прежняя схема выпуска удалена

Механизм подписанных release ZIP, ротации ключей и загрузки из GitHub Release
полностью выведен из эксплуатации. Этот файл оставлен только как явный указатель
для старых ссылок документации.

Актуальный контракт: один детерминированный `robopark-<версия>.ota`, встроенный
manifest и SHA-256, локальная/USB установка и resumable web upload для royal.
См. `docs/runbooks/build-ota.md` и `docs/runbooks/web-ota-update.md`.

SHA-256 подтверждает целостность байтов, но не личность издателя; файл должен
поступать по доверенному локальному каналу.
